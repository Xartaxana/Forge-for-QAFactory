# Цепочка ввода ходока различает поле по написанию селектора и общая для двух акторов

id: — | кучка: `thinking-roles` | от: ревью критика `docs/tasks/specs/reviews/t-2055-critic-manual-walk.md` (F10 и четвёртая строка очереди: «same_field for selector spelling, if not done in F10») | приоритет: П2 | кандидат наверх: нет

Решение владельца нужно: нет.

## Что наблюдалось

- Узел TR1-1 продолжает набор поля по строке селектора: `type #qty 1`, затем `type input#qty 2` читается как ДВА поля и даёт ('12', ok, ok) — ещё одна дорога ложного прохода, уже по написанию. Две роли (акторы) делят `rec["attempt"]`: первый `type` актора B по селектору, который только что использовал A, читается как «продолжение» на странице B — ложный сбой.
- Решение критика: в `op_step` (`scripts/walk_session.py`) сбрасывать `attempt.type_chain` при смене актора; для написания — при заданном и отличном `type_prior` спрашивать бэкенд `same_field(a, b)` (сомнение = False, то есть сегодняшняя дорога). Если раунд фикса не уложится, половина про написание идёт в очередь — эта строка и есть очередь.
- На этой основе `same_field` нет (поиск `def same_field` по `scripts/*.py` пуст; контроль той же формой нашёл `_running_verdict`), ветки TR1 не слиты — доступность половины про актора и про написание проверяется после слияния.

## Что именно менять

### TR4-9. Поле определяется бэкендом, цепочка не перетекает между акторами

- Где: `scripts/walk_session.py` (`op_step`: сброс `type_chain` при смене актора); `scripts/manual_capture.py` (бэкенд: метод `same_field(a, b)`, сомнение — False).
- Поведение: смена актора между двумя `type` обрывает цепочку (второй набор начинает поле заново); два селектора, которые бэкенд признал одним полем, продолжают цепочку; неизвестный ответ бэкенда (нет метода, ошибка) — сегодняшняя дорога (новое поле), без падения.
- Тест: `#qty` затем `input#qty` на одной странице → '12' продолжено; тот же селектор у актора B после актора A → новое поле; бэкенд без `same_field` → прежнее поведение (рядом с тестами TR1-1 в `scripts/tests/`).
- Порядок: после слияния TR1-1; если часть про актора уже сделана раундом фикса — узел сводится к написанию.

Принципы и правила: P26, P27, FR-18, AR-13.
