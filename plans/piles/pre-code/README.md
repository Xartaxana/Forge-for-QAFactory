# Прогон без кода и с одной стороной (`pre-code`)

приоритет: П2 | фичи: F05, F06, F08, F11, F13 | стенд: нужен | зона: `ai-packages/qa-factory/scripts/interim_packet.py`, `ai-packages/qa-factory/scripts/reference_snapshot.py`, `ai-packages/qa-factory/scripts/tests/test_story_sides.py`

## Зачем

Сегодня фабрика без кода изменений либо останавливается, либо пишет заведомо красные тесты с обещанием бага «не выполнено»; про моки она не
знает ничего — зелёный на замоканном бэкенде читается как обычный зелёный. Здесь строится одна схема на три случая: кода стори ещё нет,
есть только одна сторона (UI без бэкенда или наоборот), «должно работать как в старой версии». Тесты пишутся сразу, всё предположенное
(заглушка локатора, контракт, мок) лежит строкой в одном реестре допущений; стори ждёт кода и продолжается с привязки, когда его дали.

## Что не так сегодня (факты)

- Разведки t-2170, t-2178, t-2179 (10.11.2026) и раздел «Reading trail» спеки `docs/tasks/specs/t-2181-pre-code-and-one-side-runs.md`.
- Остановки после S5 и состояния «стори ждёт кода» нет: стоп только на гейтах (`ai-packages/qa-factory/scripts/story_run.py`, `UNTIL_PAST`).
- Новый `--mr` на начатой стори молча теряется: слова запуска хранятся только внутри `s0`, а `s0` пропускается, когда `pipeline.json` есть.
- Ни состояния, ни поля, ни вердикта, отличающего «зелёный на моке» от «зелёного на настоящей стороне», в пакете нет.
- Обещание бага «не выполнено» для режима без кода — только текст вопроса и фазы S1, кода под ним нет.
