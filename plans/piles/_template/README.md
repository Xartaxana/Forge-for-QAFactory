## Зачем

Три–пять строк для пользователя фабрики: что сегодня не так и что изменится. Без id и путей.

## Что не так сегодня (факты)

- факт с указателем на носитель (`файл:строка` или команда, которой его проверить), по одному на строку.

|---|---|---|---|---|---|---|---|
| 1 | одна строка словами пользователя | B-nnn, B-mmm | M | ожидает | — | — | — |

Статусы пачки: `ожидает` → `в работе` → `сдано` → `принято` → `закрыта`. Размер — по узлам: S ≤ 4 узлов,
M 5–9, L 10–15 (больше — две пачки). Взятая пачка заморожена: её файл правит только взявший, новое
по теме — файлом в `findings/`.

## Дороги

`plans/BACKLOG.md` (номера строк) → код зоны по функциям из «Слов» → документы, которые задают правила зоны.
Слова: `plans/features.json` F01 (поле `words`) и сверх них: имена функций, файлов и терминов, по которым агент ищет код.
Не читать: соседние кучки и файлы, которые узлу не нужны, с причиной в одной фразе.
