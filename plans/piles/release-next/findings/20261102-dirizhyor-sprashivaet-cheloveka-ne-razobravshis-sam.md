## Класс

Причина, вердикт или отказ кода доходят до человека вопросом, минуя разбор дирижёра (P22, P1, P9; FR-3, FR-48, FR-59; AR-2, AR-17).
Чинится одним правилом на высшем уровне, который связывает обе дороги дирижёра, и кодом на обоих путях; построчные «перед вопросом посмотри X» —
неверное направление (слово владельца). Ось — `docs/SIBLING_MAP.md`, строка «Conductor's own investigation before a question» (добавлена тем же
коммитом).

## Что именно менять

Направление выбрано (Lead, 02.11.2026, по слову владельца). Узел многошаговый — спеку пишет designer по этому разделу, критик на план (меняется
смысл гейта вопроса, PROJECT.md «Как принимается» п. 6).

1. **Одно правило — FR и AR.** `design/factory-rules.md` FR-48 дописывается: «Before any question to a person the conductor investigates the
   problem itself: it reads what the code left (records, logs, notes, the refusal's evidence) and resolves what it can; a person is asked only
   what only a person can know or decide.» Тот же инвариант — в AR-17 (`design/architecture.md`), индексы перегенерировать
   (`tools/factory_rules_index.py`, `tools/architecture_index.py`).
2. **Текст обеим дорогам дирижёра.** `skills/qa-story/SKILL.md:72` — пункт становится общим правилом (тот же текст, что в п. 1, своими словами
   для роли) и называет закрытый список «что решает только человек» (п. 4); `references/conductor.md` «How you decide» — то же правило первым
   пунктом. Тест: текст правила присутствует в обоих файлах (тест текстов ролей, как у близнецов автор↔критик).
3. **Фазы перестают учить рефлексу.** Каждая строка из п. 2 «Причины» (и строки `s2/s3/s7/s9`, которые исполнитель дочитывает сам) переписывается
   из «X → ask the person» в «X → resolve it by the rule in SKILL.md; what is left for the person is asked in the human-questions form»: фаза
   больше не диктует вопрос, а называет улики, где смотреть (поля записи, лог). Строка `s5.md:170` — так же (вместе с RN1-8 п. 3). Тест: grep-тест
   на фразы рефлекса в `phases/*.md` (белый список строк, где спрашивать — дело человека: бюджет, доступ, слово к гейту).
4. **Код на пути — закрытый класс «чьё это».** Данные: файл `references/person-owned.json` (AR-1) — классы того, что решает только человек:
   доступ, который человек может дать; толкование требования и намерения; деньги и бюджет; риск продукта; исходящее действие; субъективное
   суждение; слово, проводящее через гейт (P13). (а) Драйвер: ответ дирижёра `ask_person` несёт `why_person: <класс>` и `checked: <что прочитал>`;
   `story_run.py` (место проверки :4392) отказывает без них или с классом не из файла, и отказ говорит дирижёру «это решается тобой: <что
   прочитать>» (FR-1, FR-2). (б) Интерактивный путь: `waiver.py` принимает слово человека только с `--why-person <класс>`; без него — отказ с дверью.
   Тест на каждое: отказ без поля, проход с полем, класс не из файла — отказ.
5. **Детектор.** Калибровочная проверка или счётчик в разборе прогона: доля вопросов человеку, на которые ответ лежал в уликах фабрики (разбор
