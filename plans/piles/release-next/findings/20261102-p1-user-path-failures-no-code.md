## Что именно менять

Направление выбрано (Lead, 02.11.2026); узел RN1-5 (дизайнер доводит до строк кода).

1. **Источник мест без диффа.** `scripts/user_path_failures.py`: когда диффа нет, места берутся из файлов `context-bundle.json facts[].path` (пути, которые S1 уже записал) и из цитат реестра `current-code:`; обе выборки идут через те же шаблоны `references/user-path-failure-patterns.json`, ничего нового в код не зашивается (FR-13, AR-1). Тест: фикстура «нет диффа, есть репозиторий» с `catch` без проверки `response.ok` в файле из `facts[].path` → `matches` непуст, у места путь и строка.
2. **«no code» только когда пусто всё.** `unmeasured: ["no code"]` печатается, когда нет диффа, нет цитат реестра И бандл пуст (или пути бандла не читаются — отдельная причина с названием пути). Тест: пустой бандл, нет диффа → «no code»; бандл с одним файлом без совпадений → `checked` называет файл, «no code» нет.
3. **Отрицательный контроль.** Файл бандла без шаблонного места даёт `matches: []` и непустой `checked`: молчание отличимо от «не смотрел». Тест: два файла, в одном `catch` без проверки статуса — одно совпадение, `checked` из двух.
4. **Шаги S2 сохраняют вывод.** Совпадения идут в бриф S2 тем же путём, что сегодня (`brief_pack.py`, строка «User-path failures»); бриф S2 в фикстуре «нет диффа» несёт совпадение, а не «not measured: no code». Тест: бриф на фикстуре п. 1.
