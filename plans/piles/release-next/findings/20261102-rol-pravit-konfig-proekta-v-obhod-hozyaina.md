## Причина

Нет охраны записи в онбординговый `config.json` из ролей и дирижёра: гард пропускает запись, откат без хода («не могу откатить»).

## Класс

Роль пишет файл, у которого есть хозяин (онбординг), и ни гард, ни код не называют двери (FR-2, FR-39, FR-57; AR-14: один артефакт — один писатель; P14, P15). Фабричный класс.

## Что именно менять

Направление выбрано (Lead, 02.11.2026): запись в онбординговый конфиг — только командой онбординга; всё остальное отказ с дверью.

1. **Гард записи.** `scripts/guard_pre_tool.py` / `scripts/stage_guard.py`: Write/Edit в `qa-factory/config.json` проекта от роли S0…S9 и дирижёра — отказ с дверью «запись только командой онбординга `<команда>`; изменение для прогона — запись находкой» (FR-1, FR-2). Тест: Write роли в конфиг → отказ с названной дверью; запись командой онбординга → принято.
2. **Дверь отката.** Команда возврата конфига к записи онбординга (`scripts/` онбординг, искать по `runtime_probes`) — одна, названная в отказе; тест: после правки роли команда возвращает файл.
