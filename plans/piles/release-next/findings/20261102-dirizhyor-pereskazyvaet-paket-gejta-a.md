## Что наблюдалось

**Код собрал пакет верно.** `qa-factory/artifacts/LOCAL-1/work/gate-a-brief.md` проекта MyBooks (`gate_brief.py`, 00:48):
- первая строка — «Approve: `understanding.md`, `test-plan.md`»;
- у каждого вопроса Q1–Q9 есть карточка:
  - источники («the source says»);
  - варианты `a)`/`b)` с текстом и «if chosen»;
  - «what changes if you choose»;
  - строка `Answer: \`Qn: a\`, \`Qn: b\` or \`Qn: not needed\``;
  - скрытый маркер `<!-- card Qn <hash> -->`.

**Человек увидел пересказ дирижёра** (скриншоты владельца):
- «Полные документы: test-plan.md, requirements-register.md, case-appendix.md, кейсы в test-cases/cart/, бриф гейта» — пять документов;
- таблица «Вопрос | Суть | Рекомендация» только с буквами `a`/`b`, без текста вариантов и без «что изменится»;
- R-8, R-9, R-10 поданы как вопрос, хотя в пакете это не карточки;
- Q4, Q7, Q8, Q9 склеены в одну строку с одной рекомендацией `not needed`. Четыре разных вопроса получают один ответ, о котором человека по отдельности не спрашивали: FR-9, AR-24, и то же в П-4 разбора t-1666.

## Почему так

1. **Правило показа держится только на дисциплине.** `skills/qa-story/phases/s4.md:20`: «open with `gate_brief.py --task <TICKET> --gate A`, quoted, never rebuilt from memory». Кода, который проверил бы, что человек увидел карточки, нет. Маркеры `<!-- card Qn hash -->` есть, но их читает только применитель ответа (`gate_brief.shown_hashes`), не проверка показа.
2. **Список документов вернулся из текста навыка, не из кода.** GW1-11 (0.10.8) свёл `gate_brief.GATE_A_DOCUMENTS` к двум документам (`gate_brief.py:1758`), и код печатает верно. Но соседи этого факта остались старыми:
   - `skills/qa-story/SKILL.md:196`: «**Paths first.** The first line is the paths to the full artifacts»;
   - `evals/plugin-eval-benchmark.json:46`: «the paths to the full artifacts (test-plan.md, requirements-register.md)».

   Дирижёр исполнил их и сам собрал «полные документы». Это ось «код ↔ текст роли» (AR-16, FR-10), обход соседей GW1-11 неполный. Прежняя находка — `plans/piles/gates-and-words/findings/20261022-gejt-a-chetyre-dokumenta-vmesto-dvuh.md`, узел GW1-11, «принято, слито (релиз 0.10.8)».

## Класс

Текст, который читает человек на гейте, проходит через свободный пересказ LLM. Форма вопросов (`human-questions.md`, AR-16) соблюдена в коде, но нарушена на последнем шаге до человека. Правило «показать как есть» — без кода на пути (вопрос (d) правила 10). Тот же класс, что C5-9 `words-gates/1` (пересказ меняет слова человека), с другой стороны: здесь пересказ меняет вопросы фабрики. Не правило MyBooks.

## Что именно менять

Направление выбрано (Lead, 02.11.2026). Дизайнер доводит до функций и тестов. Критик на план нужен: появляется код-гейт на поведении дирижёра.

1. **Сообщение гейта — файл кода, показывается целиком.**
   - `gate_brief.py --gate A` пишет готовое сообщение человеку в `work/gate-a-message.md`. В нём:
     - первая строка с двумя документами;
     - карточки вопросов целиком;
     - пункты репетиции;
     - «как ответить».
   - `phases/s4.md:20` и `SKILL.md` говорят одно: напечатать этот файл целиком, свои слова — только ПОСЛЕ него, отдельным абзацем «от себя», без таблиц-пересказов вопросов.
   - Тест: файл содержит каждую карточку `open_questions` с её `Answer:` и маркером.
2. **Проверка показа на пути — хук `Stop` на открытом гейте.**
   - Пока гейт A или B ждёт ответа (запись контроллера), ход дирижёра, который заканчивается вопросом человеку, обязан содержать каждый маркер `<!-- card Qn hash -->` и каждую строку `Answer:` из `work/gate-a-message.md`.
   - Если хотя бы одного нет, ход останавливается с отказом по FR-1: «покажи человеку `work/gate-a-message.md` целиком — в твоём сообщении нет карточек Q4, Q7…». Дверь: напечатать файл (FR-2).
   - Маркеры в чате скрыты, так что человеку они не мешают.
   - Читатель — `gate_brief.shown_hashes` (один читатель, AR-13).
   - Тест: сообщение с таблицей из букв — отказ; сообщение с файлом целиком плюс абзац дирижёра — проход; гейт не открыт — хук молчит.
3. **Соседи GW1-11 по тексту.**
   - `SKILL.md:196` «Paths first» заменить ссылкой на первую строку, которую строит код. Абзац «список документов» дирижёр не пишет.
   - `evals/plugin-eval-benchmark.json:46` — ожидание по двум документам `GATE_A_DOCUMENTS`.
   - Пройти `phases/s8.md` (гейт B) тем же вопросом.
   - Тест: `grep` по навыку и evals не находит «full artifacts», «requirements-register.md» и `case-appendix.md` как документ человеку.
4. **Один ответ — один вопрос.**
   - Рекомендация дирижёра, если она есть, стоит строкой «рекомендую: `Qn: a` — почему» под карточкой, по одной на вопрос.
   - Склейка нескольких вопросов в одну рекомендацию — отказ проверки п. 2: маркеры склеенных карточек отсутствуют.

Детектор: калибровочная проверка «гейт показан не текстом кода» — счёт отказов хука п. 2 по прогонам. Живое доказательство: прогон стори до гейта A, на котором человек видит карточки целиком (`live-runs`).
