## Причина

По именам и местам кода (механизм по чтению, прогоном не проверен; первый шаг узла — воспроизвести на записи окна 1 LOCAL-1): `scripts/branch_accounting.py` `s5_scope` (`:1716`) определяет scope окна по живому диспатчу (`LIVE_DISPATCH = ("running", "returned_unaccepted")`, `:1736`; поиск единственного стейджа с живым диспатчем, `:1758`); при ремонте `returned_unaccepted`, записанном как «вернувшийся», живого диспатча нет, scope пуст, и `s5_problems` (`:1687`) судит по всему плану.

## Класс

Пустой scope проверки превращается в «весь план» вместо отказа/вывода по известному окну (FR-3, FR-4, FR-59, AR-28: неизвестное не становится проходом; неустановленное не пересчитывается на самое широкое). Дефект фабрики, поданный человеком как выбор. Фабричный класс.

## Что именно менять

Направление выбрано (Lead, 02.11.2026).

1. **Scope окна из записи окна.** `scripts/branch_accounting.py` `s5_scope`: если живого диспатча нет, scope берётся из записи окна (`scripts/window_record.py`, поле scope последнего окна стадии), а не из плана; нет и записи — код возвращает находку «scope окна не определён» с дверью, не судит весь план. Тест: окно в статусе `returned_unaccepted` без живого диспатча → scope = Then этого окна.
2. **Вне окна не судится.** `s5_problems` (`:1687`): Then вне scope окна не входят в находки окна. Тест: Then окон 2–8 при проверке окна 1 → находок нет.
3. **Не человеку.** `scripts/story_run.py` (выход окна S5; искать по `s5-branch-accounting`): находка о неопределённом scope — ремонт кода/дирижёра, вопрос «принять Then без привязок вне окна» не строится (RN1-9). Тест: вопрос не создаётся.
