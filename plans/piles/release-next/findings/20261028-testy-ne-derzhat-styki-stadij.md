## Пробел в детекторах (по `design/architecture.md`)

AR-22: «Detector: `test_field_producers.py` covers the handoff contracts only. Elsewhere: none — discipline.» Обхода «что проверяет гейт → кто это пишет → где это сказано роли» нет ни для гейтов выхода, ни для квитанций окон, ни для формы дайджеста. Юнит-тесты гейта проверяют гейт на подложенных входах, юнит-тесты роли/скрипта — их выход; стык между ними не проверяет никто.

## Направление (проверить, не утверждать)

1. Реестр требований гейтов: каждая проверка гейта/окна/дайджеста — строка с продюсером (скрипт, поле роли) и местом, где требование сказано роли (агент, бриф, карточка); обход в обе стороны в `selftest.py --contracts` (CI `package-fast`); строка без продюсера или без текста роли — красный.
2. Тест стыка на записанном прогоне: артефакты реального прогона (12586) как фикстура; выход стадии N подаётся в гейт стадии N+1; отказ гейта на настоящем выходе роли — красный.
3. Счётчик трения в метриках прогона: `gate_block` одного класса > N за прогон — сигнал дефекта кода (FR-55), не роли.
4. Связь с F6-42: замер считает, сколько проверок держат стык, а сколько пинуют одну сторону; сокращать — второе.

Решение по объёму (что удалить, что заменить тестом стыка) — за владельцем по числам F6-42.
