# Один дом в `contract` для закрытых слов исхода (`blocked_by_env`, `handed_to_person`, `probe_gap`) и один читатель «в строке манифеста есть красное слово» (t-205 F7, HF8-4)

## Что наблюдалось

В HF8-4 (P1-P5) слово `contradicts_requirement` получает один дом `contract.CONTRADICTS_REQUIREMENT` (14 написаний в 12 файлах → один). Тот же класс остаётся для других закрытых слов исхода/пробела, записанных литералами и словарями в нескольких модулях: `controller.py:225-233`, `acceptance.py:27, 41, 53`, `contract.py:112`, `s5_precheck.py:199`, `story_step.DERIVED_GAP_KINDS` (слова `blocked_by_env`, `handed_to_person`, `probe_gap`; перечень строк — по дереву после слияния HF8-4, заново). Читатель-двойник (замечание t-213 m9): `driver_stage_s7.py:44` и `s7_pretriage.py:129` оба читают «слово где угодно в `json.dumps(entry)`» (докстринг `s7_pretriage` сам говорит «as the driver finds it»); две копии одного правила «строка манифеста несёт красное слово». HF8-4 это не делает, чтобы P2 (`controller.py`, горячий файл) остался диффом в одно слово.

## Что именно менять

Направление выбрано (спека t-205 §5 F7). Исполнитель — `designer → builder → critic` (точные имена выбирает дизайнер; здесь — рабочие). Начинается ПОСЛЕ слияния HF8-4 (`onboarding-forge/2`): нужен готовый `contract.CONTRADICTS_REQUIREMENT`; `controller.py` — горячий файл, список функций в `owns` диспатча.
1. Дом слов: в `contract.py` константы `BLOCKED_BY_ENV`, `HANDED_TO_PERSON`, `PROBE_GAP` (значения — прежние строки, не меняются: это AR-1-данные в схеме манифеста); каждое место из перечня импортирует константу (ленивый импорт там, где модуль сегодня `contract` не грузит при загрузке — как в HF8-4 §6 b). Псевдонимы остаются ТОЛЬКО там, где читает модуль снаружи.
2. Один читатель: `contract.row_carries(entry, word) -> bool` — единственная реализация «слово встречается в `json.dumps(entry)`» (направление ошибки — то, что даёт сегодняшний код двух копий; если копии на каком-то входе расходятся — это развилка наверх, строка в отчёте дизайнера, не выбор исполнителя); `driver_stage_s7.py:44` и `s7_pretriage.py:129` зовут его.
3. Тест: (а) сторож — перепись литералов трёх слов по `scripts/*.py` (кроме `contract.py`, данных `references/*.json`/`handoffs/vocabulary.yaml`, тестов) пуста; список допустимых — shrink-only; (б) `row_carries` — таблица: слово в значении, в ключе, во вложенном списке, регистр, подстрока другого слова (`blocked_by_env_x`), пустая строка, `None`-вход — ожидание и направление ошибки названы в спеке дизайнера; оба вызывающих дают одинаковый ответ на каждую строку.
