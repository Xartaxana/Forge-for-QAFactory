   что следующий новый `delegated` — `t-NNN`. Собственный `task_id` строке не нужен: поле допустимо на служебных событиях
   (`journal_created`, `decomposable`, `calibrated`) — пишущий выбирает событие, которое у него уже есть по смыслу.
2. Читатель: функция `max_task_num` (:360) получает второй вход (объявленные границы) и возвращает `max(макс. id в файле, NNN - 1)`; правило 9а остаётся
