# Релиз-бот: ярлык MR → semver, CHANGELOG, заметка релиза и тег собираются в CI в режиме preview — брать подготовительную часть

id: — | кучка: `onboarding-forge` | от: обзор testing-factory (docs/RELATED_WORK.md §2), владелец 21.10.2026 | приоритет: П3 | кандидат наверх: нет

Что не так / что сделать: у Testing Factory релиз-бот на `main`: ярлык MR `release:patch|minor|major|none` задаёт semver; бот правит
`package.json`/lock/CHANGELOG/README/`docs/releases/<v>.md`, проверяет версии и что изменились только релизные файлы, делает
коммит `chore(release): vX [skip ci]` с трейлером `Factory-Release-Source`, `git push --atomic` ветки и тега через askpass
(токен не в argv), создаёт GitLab release; по умолчанию режим preview (патч лежит в артефактах CI). У нас релиз — копия
каталога `ai-packages/qa-factory/` в `tp1-group/QAFactory` по слову владельца (раздел «Релиз» PROJECT.md, отпечаток
D-0052), MR туда — только Draft, сборка CHANGELOG из фрагментов `changelog.d/` руками (`scripts/changelog_assemble.py`). Брать
только подготовительную часть, не публикацию: в CI в режиме preview — версия по ярлыку MR, сборка CHANGELOG, заметка релиза,
проверка «изменились только релизные файлы», отпечаток; тег и публикация остаются за словом владельца (RELATED_WORK §2, K10:
«средне; слово владельца»). Для спеки дизайнера (решает Lead): стыковка с шагом отпечатка `release_fingerprint.py` и с
правилом «релизный коммит с фрагментами не делается»; токен не в argv; пуш на git.example.com — только под VPN (то, что CI-бот
не может, остаётся шагом человека).

Свидетель: репозиторий `git.example.com/tst/testing-factory` (v0.1.33, `main` cda7f7e): `ci/release.mjs` строки 80–200, ADR
0041/0042 (содержание — `docs/RELATED_WORK.md` §2 п. 11; 29 релизов 0.1.5–0.1.33 за 12–20.10 релиз-ботом). Клон в скрэтчпаде
сессии Lead, пересобрать по SSH — см. §2.

Принципы и правила: раздел «Релиз» PROJECT.md, D-0052.

Решение владельца нужно: нет (слово владельца 21.10.2026: положить в кучки, сейчас не брать; публикация и тег — по слову
владельца при взятии узла).
