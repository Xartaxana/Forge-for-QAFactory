## 1. Предел 260 знаков на пакете нативного контекста (OH3-36)

**Что наблюдалось.** Тест `test_doctor_context.DoctorContext.test_probe_passes_actual_hooks_with_existing_stories` красен на базе
`4195b775` на этой машине (две ошибки подтестов). Хук записал сигнал `inject` (`qa-factory/records/journal.jsonl`, `hook_signal`) с
`FileNotFoundError` на пути `<корень>\qa-factory\state\native-context\<sha256>-<sha256>.json.<32 hex>.tmp`. Строка пути — ровно **260**
знаков при корне в 56 знаков. Контроль критика: тот же тест на том же дереве с `TEMP` на более короткой папке — `Ran 1 test ... OK`.

**Причина.** `native_context.stage` пишет пакет через `atomic_json` (временный файл с суффиксом из 32 hex рядом с целевым); на Windows
без длинных путей путь длиннее 259 знаков не открывается. `inject_context.py:484` стоит под `is_codex`: при ошибке записи остаётся
только сигнал в журнале, запуск именной роли разрешён — **роль идёт дальше без контекста**. Исправляет заметку спеки Н-7 («длинный
TEMP»): чем длиннее путь, тем больше отказов, не меньше.

**Не измерено:** превышают ли предел стенды владельца (корень проекта длиннее 55 знаков). Мерить до решения.

**Что сделать (класс, не экземпляр, AR-9, FR-41, AR-28).** Либо короче имя пакета (один `sha256` и без второго 32-hex суффикса временного
файла), либо при ошибке записи пакета на Codex запуск именной роли не разрешается молча, а отказывает с названной причиной и дверью
(FR-1, FR-2); и тест на корне длиннее 55 знаков, не зависящий от `TEMP`. Файлы: `scripts/native_context.py`, `scripts/inject_context.py`,
`scripts/hooklib.py` (`atomic_json`), их тесты. Пока не сделано, красный тест на этой машине — не регрессия диффа.
