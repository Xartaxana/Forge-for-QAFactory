## Что не так / что сделать

Что не так: что запускать билдеру как свидетеля правки, называет одна команда — `scenario_walk.py --witness-for <owns>` (хост-адаптация 12, `docs/TESTING.md`). Она отвечает только за пути пакета `ai-packages/qa-factory/`. Для пути вне пакета (`tools/x.py`, хуки) свидетеля называет диспатч руками: «тестовый файл, который судит путь» (`PROJECT.md`, «Как принимается изменение пакета», п. 2). Это два пути для одного действия (P31): какой путь идёт какой дорогой, решает координатор по памяти.

Что сделать (направление выбрано — рекомендация дизайнера t-013 F5, Lead 11.11.2026):

1. `ai-packages/qa-factory/scripts/tests/scenario_walk.py`, ветка `--witness-for`: для пути вне пакета печатать судящий тест. Правило по умолчанию — `tools/<имя>.py` → `tools/test_<имя>.py`, если файл есть; исключения — строками данных (где им жить — `test-layers.json` или карта на стороне форджа — решает дизайнер узла, AR-1: закрытое разнообразие — строка данных, не список в коде).
2. Путь, для которого судящего теста нет, не молчит: строка «свидетеля нет: <путь>» (FR-41, неизвестное не выдаётся за факт), код выхода прежний.
3. Тест: строка таблицы `witness_for` на путь форджа с тестом, на путь без теста и на путь пакета (прежнее поведение не меняется).
4. После узла — убрать из нового текста `CLAUDE.md` и из `PROJECT.md` п. 2 оговорку «для пути вне пакета свидетеля называет DoD».
