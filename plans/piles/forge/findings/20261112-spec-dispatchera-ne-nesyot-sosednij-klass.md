## Что именно менять

Направление выбрано по записи калибровки: код проверяет НАЛИЧИЕ перечня соседей в диспатче, смысл перечня судит критик/Lead (P27, AR-29);
сообщает, но не останавливает (P1, FR-4: проверка не мешает осознанному проходу). **Рекомендация составителя находки; решение владельца
нужно (это изменение механизма, правило 10 `CLAUDE.md`) — исполнить по рекомендации до ответа.**

1. `tools/dispatch_manifest.py`: новая проверка заголовков писательского диспатча (диспатч билдеру или с `owns:` из абсолютного пути): в
   тексте должна быть строка-заголовок `neighbors:` (перечень соседей по `docs/SIBLING_MAP.md` — пути или оси) либо
   `neighbors: none -- <причина>` (форма «no neighbors: <why>» правила 9). Нет строки или пусто после двоеточия — WARN, не отказ; текст
   называет, что ожидалось и как пройти (FR-1, FR-2): добавить строку или `manifest-skip: neighbors -- <причина>` (дверь уже есть
   в `CLAUDE.md` R11-f). Тест: `tools/test_dispatch_manifest.py`, один параметризованный тест, строки случаев: строка есть с путями /
   `none -- причина` / пусто после двоеточия / строки нет (красный) / `manifest-skip: neighbors` (проходит) / диспатч скауту (не
   проверяется) / регистр `Neighbors:` (как у остальных ключей заголовка — поведение копируется из читателя `owns:`).
2. `tools/warn_layers.json`: слой для новой проверки с объявленной «достижимой популяцией» (писательские диспатчи), чтобы калибровочная
   проверка 11 (`tools/warn_density.py`) считала его долю; тест реестра `tools/test_warn_layers*.py` (если есть — иначе строка в
   свидетеле) красный на слое без популяции.
3. Детектор: калибровка проверка 15 — следующий прогон считает кластер A; ожидание 0 новых отказов класса (запись в
   `PROCESS/WEEKLY_CALIBRATION_PROTOCOL.md` — Lead).

Края: диспатч без `owns:` вовсе — проверка не срабатывает (уже отказ по `owns`); `neighbors:` внутри fence/цитаты не читается как заголовок
(тот же читатель, что у остальных ключей).

Исполнитель: designer → builder → critic (изменение механизма: четыре вопроса правила 10 в сообщении коммита).
