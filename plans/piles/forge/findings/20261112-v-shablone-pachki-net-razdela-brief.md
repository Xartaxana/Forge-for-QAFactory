## Что не так

Класс фабрики: «форма, которой файл рождается, и проверка этой формы — из одного источника» (AR-19, FR-54; сестра — шаблон карточки, для
которого это уже закреплено тестом `test_the_template_carries_every_card_heading`). У шаблона пачки такого соответствия нет.

`plans/piles/_template/batch.md` содержит заголовки `## Узлы`, `## Ход`, `## Живые доказательства`, `## Остатки`, но не `## Бриф`
(проверено чтением файла: строки 18-82, заголовка «Бриф» нет). А `tools/piles.py` требует его у файла НЕвзятой пачки:
`BATCH_HEADINGS = ("## Бриф", "## Узлы")` (`tools/piles.py:1948`, комментарий там же: «the headings an untaken batch file is born with
(plans/piles/_template/batch.md)» — шаблон этого не выполняет; описание проверки — `tools/piles.py:54`), и
`tools/test_pile_cards_contents.py` `BATCH_HEADINGS = ["## Бриф", "## Узлы"]` (`:31`), тест `test_card_and_batch_headings` (`:61-74`) читает
каждый файл пачки каждой кучки. Новая пачка, открытая из шаблона 12.11.2026, покраснела ровно на этом. Живые пачки несут раздел как
две строки: «Что сделать: … НЕ делать: …» (образец: `plans/piles/forge/batch-7-vhodyashchie-4.md`, раздел `## Бриф`).

## Что именно менять

Направление выбрано (Lead, 12.11.2026).

1. **`plans/piles/_template/batch.md`.** Раздел `## Бриф` между шапкой («Правило готовности … Общий бриф дизайнерам») и `## Узлы`, с
   текстом из двух строк: «Что сделать: <что делает пачка одной фразой>. НЕ делать: <чего пачка не трогает>.» Заглавие раздела —
   ровно `## Бриф` (читатель сверяет строку целиком). Ожидание: файл, скопированный из шаблона без правок, проходит
   `piles.batch_heading_problems`. Край: строки комментария-справки в шаблоне не должны содержать заголовка `## Бриф` вне раздела
   (читатель считает заголовком любую строку, начинающуюся с `## `).
2. **`tools/test_pile_cards_contents.py`.** Существующий тест заголовков идёт и по файлу шаблона: к параметрам
   `test_card_and_batch_headings` (или соседний тест по образцу `test_the_template_carries_every_card_heading`, `:77-82`) добавляется
   файл `plans/piles/_template/batch.md`, и по нему сверяется `BATCH_HEADINGS` через `piles.batch_heading_problems` — тот же читатель, что у
   гейта. Тест: красный на шаблоне без `## Бриф` (контроль: текущий шаблон), зелёный после пункта 1.
   Свидетель: `python -m pytest tools/test_pile_cards_contents.py -q`.
