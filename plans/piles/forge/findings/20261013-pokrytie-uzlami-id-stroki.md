Что не так / что сделать: узлы файлов первых пачек получили id вида `<инициалы кучки><N>-<n>` (`DC1-1`, `GW1-1`, `KB1-1`), а id строк
BACKLOG стоят в начале ячейки «Что» (`B-311, B-317: …`). Проверка формы `piles.py check` (д) сверяет узел со строкой карточки
только когда id узла сам похож на `B-nnn` (`_placement_form`), поэтому правило «каждый id строки карточки стоит ровно в одном
узле её файла пачки» кодом не держится: сегодня его держит тест `tools/test_pile_cards_contents.py` (идёт в CI `forge-check`
вместе с `pytest tools/`). Сделать: добавить в (д) проверку «каждый член строки карточки встречается в «Что» ровно одного узла
файла этой пачки, а в «Что» узла нет id, не входящих в строку» (с дверью для частичных членов и для узлов-сверок); после этого
тест покрытия узлами можно сузить до «Содержания».
