# Исследовательское тестирование функции по чартерам (`exploratory`)

приоритет: П2 | фичи: F23, F02, F08 | стенд: нужен (MyBooks, RUNBOOK §11) | зона: `ai-packages/qa-factory/skills/qa-explore/`, `scripts/requirement_search.py`, `scripts/feature_map.py`, `scripts/feature_hits.py`, `references/feature-map-form.json`

## Зачем

Сегодня фабрика тестирует одну стори: читает тикет по ключу и смотрит на код от диффа. Попросить её «проверь всё, что
связано с добавлением в корзину» нельзя. Такой запрос сейчас выполняется руками: требования ищутся во всех источниках,
код функции — по всем репозиториям, кейсы и тесты сверяются с приложением, дыры закрываются. Кучка добавляет скилл
`/qa-factory:qa-explore "<функция>"`, который делает это сам: находит требования и код функции, сверяет покрытие,
придумывает чартеры с гипотезами, исследует приложение и пишет недостающие тесты.

## Что не так сегодня (факты)

- Jira читается только по ключу (`scripts/source_inventory.py:575`, `/issue/{key}`); grep `jql|/search` по `scripts/*.py` пуст, тот же grep находит `/issue/` (t-1629).
- Область кода строится от диффа стори (`scripts/blast_radius.py:1-19`); карты функции по всем `code_repos` нет.
- `requirements_sources` в конфиге без производителя и читателя (`onboarding-hooks`, OH3-39).
- Руки агента — только HTTP и браузер (`scripts/manual_capture.py:996`); desktop и mobile — `execution-probes`, EP1-41.
- Чартеров, гипотез, осей возмущений, карты швов в пакете нет; есть журнал наблюдений `scripts/exploratory_findings.py` (story-scoped, `--task-root`).
