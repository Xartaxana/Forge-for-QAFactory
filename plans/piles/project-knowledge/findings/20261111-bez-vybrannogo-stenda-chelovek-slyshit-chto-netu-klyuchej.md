# Без выбранного стенда человеку говорят «нет ключей», а не «стенд не выбран»

id: — | кучка: `project-knowledge` | от: критик t-2361 (L2) по узлу PK0-5, коммит 0d621b69a | приоритет: П2 | кандидат наверх: нет

Решение владельца нужно: нет — текст человеку чинится по FR-1 / FR-20 / FR-6.

## Что наблюдалось

`Driver.stand_login_problem` при роли без выбранного стенда возвращает вид `missing_key` (так предписала спека). Вопрос человеку
`stand_login_question_text` берёт фразу из `Driver.STAND_LOGIN_REASONS[kind]` — «файл настроек не содержит имя или пароль аккаунта». Реальная
причина другая: стенд не выбран. Тот же сплющенный текст уже есть у отказа чтения роли.

## Что именно менять

Класс: причина отказа не доходит до человека своими словами (ось карты «Вопрос о входе на стенд и отказ раннера»). Решение: у отказа есть
собственный вид (например `no_stand`) со своей фразой в `STAND_LOGIN_REASONS` и ответом по форме `human-questions.md`; `stand_login_problem`
возвращает его вместо `missing_key` для случая «нет выбранного стенда». Файлы: `ai-packages/qa-factory/scripts/story_run.py`
(`stand_login_problem`, `STAND_LOGIN_REASONS`, `stand_login_question_text`). Тест: нет выбранного стенда → вопрос называет, что стенд не
выбран, а не что нет ключей.
