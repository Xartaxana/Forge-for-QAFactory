# Карточки пробелов стенда не несут строк цены

id: — | кучка: `project-knowledge` | от: остаток R-2 (ii) спеки `docs/tasks/specs/t-2142-project-knowledge-phase0.md` §6 и развилка FK-9 (b) | приоритет: П2 | кандидат наверх: нет

Решение владельца нужно: да — это текст, который читает человек; владелец может предпочесть сделать сейчас (рекомендация Lead: со следующим
проходом по текстам пакетов гейтов).

## Что наблюдалось

Класс фабрики: карточка человеку без строк цены (пункт 6 `human-questions.md`: что берёт на себя фабрика, что — человек, что будет с
историей). Новые карточки узлов PK0 несут свои строки цены (FK-9 (a), из `options` строки). Общие слова пробелов стенда в
`question-vocabulary.json` (`stand_gap_words`) их не несут, поэтому каждая карточка пробела стенда на обоих гейтах печатается без цены.

## Что именно менять

Файл: `ai-packages/qa-factory/data/question-vocabulary.json` (путь уточняет спека узла), строки `stand_gap_words`: КАЖДОЙ строке добавить
поля `factory`, `you`, `story` (три строки цены) — по форме, которую печатает `_card` через `_price_labels`. Ожидаемое поведение: каждая
карточка пробела стенда на гейтах A и B содержит три строки цены; пакеты и тесты гейта B, где слова пробелов стенда печатаются, меняются
в том же коммите (читатель и производитель — одним коммитом, AR-22). Тест: параметризованный по всем строкам `stand_gap_words` — у каждой
три непустые строки, id параметра называет строку (P16); контроль: строка без поля — красный тест.
Рекомендация: делать со следующим проходом по текстам пакетов гейтов; если владелец хочет сразу — отдельный узел без зависимостей.

Принципы и правила: FR-6, FR-10, FR-13, AR-16, AR-22, P9.
