Что видно (ветка OH1-10 wt-t1161 на 1c2b5c47, то же на `main` для A13): `audit_factory.py:860-864` (A13 deferred decisions) ищет
иголку `risk areas not named` во ВСЁМ тексте `qa-factory/factory-backlog.md`, а не в ячейках сути открытых строк DD-N. Пример в
`references/templates/factory-backlog.md:38-39` («(risk\nareas not named, …») копируется в каждый новый проект
(`onboard_apply.py:103-104` TEMPLATE_COPIES); сегодня иголка промахивается только из-за переноса строки после «risk». Проба критика
(scratch-проекты, маркер в test-strategy.md и aspect-profile.md, строки DD нет): как есть — «VIOLATIONS (2)»; шаблон перевёрстан
в одну строку — «no violations» без единой строки DD. Косметическая перевёрстка шаблона отключает единственный детектор R3 для
маркера. OH1-10 (фикс-раунд, §L-3 F-2) переформулирует пример шаблона; иголка остаётся по всему файлу — класс «пара сопоставляется
по сути вне ячейки» (критик, правило 15).

Что сделать: (а) A13 сопоставляет маркер только с ячейками сути открытых строк DD-N (парсер строк, не `in text`); (б) статический
тест пакета: у каждого маркера `[DEFERRED: …]`, который пишут фазы онбординга (p4-generate.md), есть команда `project_decisions.py add`
с той же сутью в том же шаге — тема 4 первая (t-1163 §L F-3: «static test + A13 topic 4»); негативный контроль — маркер без команды.
