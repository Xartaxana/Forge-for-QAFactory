# Остатки спеки t-203: общий суффикс временного имени `_publish` (F-2), отказы нативного контекста без записи отказа (F-6), развилка F-5 закрыта

## Что наблюдалось

**F-2.** `event_store._publish` (`event_store.py:162`) пишет через временное имя `.<uuid4 hex 32>.tmp` — 37 знаков на каждом писателе пакета (`native_context.py` держит это числом в формуле `PACKET_ROOT_LIMIT`; на ветке `wip/oh3-36` — `TEMP_NAME_EXTRA = 37`). Укорочение суффикса 32 → 8 hex даёт +24 знака каждому писателю: пакет и привязка 119 → 143, безымянный 152 → 176, квитанции около 145 → 169.

**F-6.** Три существующих отказа нативного контекста (по спеке t-203 — размер, идентичности и `StateConflict`; §6 той же спеки зовёт их «native `ValueError` refusals») бросаются ВНУТРИ `native_context.py`, а проверка A24 (`refusal_registry.py`) видит только `deny(...)`, `block(...)` и брошенные `StateConflict`/`ValueError` в модулях, которые она читает: отказ из `native_context.py` ей невидим, строки A24 у них нет, строки `note_denial` тоже. Критик t-203: если превратить их в `StateConflict`-отказ, `recover` может закрыть запуск, который на самом деле ждёт, — поэтому в t-203 они не меняются.

**F-5 (закрыто, узла нет).** `native_context.pending_path` оставлен как есть: удаление перевело бы 14 живых мест тестов на приватный `_slot`. Решение координатора «по рекомендации, до слова владельца» (13.11.2026): оставить; OH5-11 закрывается копией в `worker_lifecycle` и очередью копий (`findings/20261113-kopii-proverki-odnoj-komponenty-puti.md`). Если слово владельца будет «убрать» — это новый узел, не продолжение этого.

## Что именно менять

Направление выбрано координатором (13.11.2026, «по рекомендации, до слова владельца»).

1. **F-2 — `event_store._publish`:** временное имя `.<8 hex>.tmp`; файл временного имени открывается в режиме `"x"` (создание, не перезапись), так что совпадение имени у двух одновременных писателей на одну цель — ошибка (`FileExistsError`), а не перемешанные байты; на `FileExistsError` писатель берёт новое имя и повторяет (до 8 попыток, как у `replace_file`; после — исключение наружу). Тем же узлом, в одном коммите: `TEMP_NAME_EXTRA` и формула в `native_context.py` (37 → 8 + 5 = 13: считать по коду, не сочинять), `SUPPORTED_ROOT`/`PACKET_ROOT_LIMIT` пересчитаны из формулы (119 → 143 при суффиксе из 8 hex; число подтверждает тест), правило нормализации золотых прогонов `driver-golden-rules.json` N8a (`[0-9a-f]{32}` перед `.tmp` → `[0-9a-f]{8}`) и его строка в `scripts/tests/test_driver_golden.py`. Файл ядра (`event_store.py`): критик обязателен.
2. **F-6 — отказы нативного контекста:** каждый из трёх существующих отказов нативного пути (найти перечнем: `grep -n "raise " native_context.py`; три названия — в отчёте билдера) получает строку `note_denial` в `inject_context.py` через `block(...)` (форма нового отказа t-203, A.2.2: `refuse_native_packet`) и строку A24 в `refusal_registry.py` в том же коммите. Исход каждого отказа (какое исключение, что делает `recover`) НЕ меняется.
3. **Тесты.** F-2: таблица в `scripts/tests/test_event_store.py` (keep-файл ядра): имя временного файла содержит ровно 8 hex; два писателя на одну цель при принудительно совпавшем имени (подмена `uuid4`) — второй берёт новое имя, целевой файл целый; длина записанного пути пакета для корня 143 знака ≤ 259. Мутация: вернуть 32 hex — красит строку длины. F-6: по строке A24 на каждый из трёх отказов; отказ, как и раньше, не двигает запуск (`recover` не закрывает ожидающий).
