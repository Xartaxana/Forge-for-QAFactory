# Читатель бродячей строки вопроса гейта A не видит `q3: x`, `Q3 - x`, `Q3 x`, `Q3. x`: такие строки уходят под печать молча (t-542 F8)

id: — | кучка: `words-gates` | от: критик t-542, F8 (`docs/tasks/specs/reviews/t-542-gate-answers-critic.md`), 31.10.2026 | приоритет: П2 | кандидат наверх: нет

## Что наблюдалось

Проба критика над `question_register.question_lines_unread` (GW1-34): видит `Q3: x`, `- Q3: x`, `**Q3**: x`, `Q3 = x`; НЕ видит `q3: x`, `Q3 - x`, `Q3 x`, `Q3. x`.
Причина в коде этой ветки: `_stray_lines` (`question_register.py:993`) берёт `_TOKEN.fullmatch(content)` (`:498`: id, затем `[:=]`) и сверяет `id` с `now_rows` точным
сравнением строк. Нет разделителя `:`/`=` или другой регистр — строка не «начинается с id реестра» для читателя. Решение GW1-34 «план запечатывает решение гейта, поэтому
строка про вопрос реестра должна быть прочитана ДО записи» (AR-24) для таких строк не работает: ответ записывается, строка человека потеряна.
`_stray_lines` общий с `gate_words_view` (AR-13): правка читателя одна, на обе дороги. Соседние классы (критик): длина — R9 режет с показом; ограждение и цитата — R5, R6
покрыты; пустое — R3; кодировка — не проверена (в этой правке проверить: BOM и `\xa0` перед id).

## Что именно менять

1. `question_register.py`, `_stray_lines` (:993): строка вне ограждений и цитат, НАЧИНАЮЩАЯСЯ с id открытого вопроса реестра (сравнение без учёта регистра; после id — граница слова:
   пробел, `:`, `=`, `-`, `.`, `,`, `)` или конец строки), которая не является токеном ответа, считается бродячей. Новый вход — регулярка начала строки
   `^[\s\-*•>]*[*`]*(?P<id>[A-Za-z][\w-]{0,63})(?=[\s:=.,\-)*`]|$)`, id сверяется с `now_rows` по `str.casefold`; возвращаемый `ident` — id в написании реестра. Строка вида «Q3 is unclear» ТОЖЕ бродячая:
   это нормально, направление ошибки — «показать человеку, что не записано» (FR-59), а не молча потерять.
2. Не менять `_TOKEN`: настоящий токен ответа остаётся прежним (`Q3: a`); читатель токенов и читатель бродячих строк — две функции с разными задачами.
3. Тесты (`scripts/tests/test_question_lines_unread.py`): таблица входов `q3: x`, `Q3 - x`, `Q3 x`, `Q3. x`, `Q3\xa0x`, `﻿Q3: x` (BOM) — каждый даёт запись `{id: "Q3", line}`; контроли
   `Q30: x` (другой id), `Quote: x`, слово «Q3» посреди строки, строка в ограждении — не дают. Мутация: сравнение без `casefold` — красит `q3: x`.
