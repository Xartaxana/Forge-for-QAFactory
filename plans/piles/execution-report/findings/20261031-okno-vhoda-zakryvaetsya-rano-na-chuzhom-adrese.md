# Окно входа ручной проверки закрывается раньше времени на чужом адресе страницы входа: поздние снимки могут показать учётку (t-506 §10 п. 1)

id: — | кучка: `execution-report` | от: спека t-506 §10 п. 1 (`docs/tasks/specs/t-506-s4-manual-capture.md:436`), 31.10.2026 | приоритет: П2 | кандидат наверх: нет

## Что наблюдалось

`manual_capture.SessionAccount.watch` (`manual_capture.py:2110`) закрывает окно входа (в нём экран не сохраняется, форма может показывать учётку, E10), когда URL страницы НЕ содержит ни одного фрагмента `url_not` правила посадки. Умолчание `url_not` —
`/auth/sign-in`, `openid-connect` (адреса одного проекта). У проекта со страницей входа на другом адресе после первого `fill-account` (`account.window = True`, :2250) URL ещё страница входа, но фрагментов из списка в нём нет — окно закрывается сразу,
следующие снимки (`capture`) показывают форму, возможно с учёткой. Частично лечит EP1-31 (`login.landed`), но только для новых онбордингов. Класс: условие закрытия охраны завязано на данные одного проекта, а не на факт «страница ушла со страницы входа» (P2; AR-3). Ошибка в опасную сторону (больше экрана, чем нужно).

## Что именно менять

1. `manual_capture.py`, `SessionAccount`: поле `signin_url` — URL страницы, на которой набран `fill-account` (запоминает место, где ставится `account.window = True`, :2250: передать URL текущей страницы в `open_window(url)`).
2. `SessionAccount.watch` (:2110): окно закрывается только когда URL (1) не содержит ни одного `url_not` И (2) не совпадает с `signin_url` по хосту и пути (запрос и фрагмент не считаются). URL не прочитан — окно открыто (как сегодня). `url_not` пуст — окно по-прежнему не закрывается (ошибка в сторону меньшего экрана).
3. Инвариант: условие (2) только УДЕРЖИВАЕТ окно открытым дольше; никогда не закрывает раньше, чем закрыл бы прежний код.
4. Тесты (`scripts/tests/test_manual_capture.py`, заглушка бэкенда с `current_url`): страница входа `https://x/login` (нет в `url_not`) — после `fill-account` окно открыто, пока URL = `https://x/login`; после ухода на `https://x/home` — закрыто; `?next=` в запросе того же пути окно не закрывает; `url_not` пуст — открыто; `current_url()` бросает — открыто. Мутация: убрать условие (2) — красит первый.
