# Аналоги RH1-8 (билдер t-1431): точный ключ в `lifecycle_reasons`, `immutable_proof` без `cfg`, молчаливый `except: continue` в `collect_cases`

id: — | кучка: `execution-report` | от: билдер t-1431 (RH1-8 HF4-1) и спека t-1430 §10 (А9), Lead, 28.10.2026 | приоритет: П3 | кандидат наверх: нет

Источник: строка диспатча t-1437 плюс спека t-1430 (раздел 10, А9 для третьего пункта); отчёта билдера t-1431 в репозитории нет, первые два пункта записаны по строке диспатча без дополнительных подробностей.

Что не так (три аналога одного класса «карта и доставка читают дело по-разному»):

1. `check_delivery.lifecycle_reasons` читает признаки `handed` / закреплённости (`pinned`) по точному ключу, а не через общий предикат, которым теперь читают `case_stamp`, `collect_cases`, `_cases_held` (ключ согласия трёх читателей, RH1-8 B2). Спека t-1430 оставила `lifecycle_reasons` как есть (F2(a)); расхождение читателей остаётся.
2. `case_stamp.stamp()`: `immutable_proof` вызывает `case_matches` без `cfg` — конфигурация разрешается заново на каждый вызов (аналог PERF-блока `test_case_id_form_sites.py`, E12 спеки: `cfg` один раз на историю).
3. `check_coverage.collect_cases` содержит `except Exception: continue`, который проглатывает сломанный элемент: при сломанном join `--write` записывает меньший счёт с годной квитанцией. Неизвестное выдано за факт (FR-41, класс RH1-5 «неизвестное — не пройдено»). Поведение сохранено узлом RH1-8 (А9).

Что сделать: каждому пункту — вердикт и правка по плану дизайнера: (1) читатель через тот же предикат или строка «другое решение — почему»; (2) `cfg` передаётся в `case_matches` из `stamp()`, ключ PERF; (3) сломанный элемент поднимается или даёт явное «не проверено» и выход ≠ 0 у `--write` (квитанция меньшего счёта не выдаётся).

Края: сломан один элемент из многих — остальные считаются, итог помечен «не полон»; пустая популяция держится (как решено в RH1-8 E4).

Свидетель: `docs/tasks/specs/t-1430-rh1-8-status-unit-and-probe-order.md` §10 (А9), E8, E12; журнал `logs/journal/dev1.jsonl` t-1431.

Принципы и правила: FR-41, FR-59, AR-12, AR-13, AR-28.
