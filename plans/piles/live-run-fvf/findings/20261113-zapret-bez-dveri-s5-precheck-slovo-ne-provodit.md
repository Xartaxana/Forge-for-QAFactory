## Что не так

Класс фабрики (P2): **запрет без двери: проверка не проходит ни по какому слову человека** (P13 «слово человека проводит
фабрику через любой гейт, проход записывается»; FR-57 «запрет не обходится и не тупик»; P15; FR-4 «проверка останавливает
молчаливый проход, а не осознанный»).

Один производитель — `scripts/s5_precheck.py:4679`. Правило `_passable` (`:3930-3933`): семейства `CHECKS` (9, `:72`) вне
`PASSABLE` (2, `:82`) — **7 семейств**: `manifest`, `bindings`, `oracle`, `run_mapping`, `smell`, `plan`, `sides`; исключения —
три тега `WORD_PASSABLE_TAGS` (`:101`) и тег ожидания `then-remainder-unrecorded-*` (`:3945`). Читатель класса —
`exit_gate.word_class` (`scripts/exit_gate.py:1785-1804`, значение `"refused"`). Обоснование в коде
(`s5_precheck.py:80-82`): «a repair the author can make without asking anybody» — правило дизайна, не слово владельца;
записанного решения владельца, запрещающего проход, для этих семейств спека не нашла.

## Что менять

То, что говорит раздел спеки (§3.6 и N-L R-L5): правило класса — **гейт проходит по слову человека, проход записывается в
`passed-by-person`**; запрет в хуке называет дверь. Сегодняшние 7 семейств в сухой стори (слой C4г) краснеют как `known_red`
с этой находкой, пока не починены; вопроса владельцу по ним нет (решение Lead №9). Находка нужна строкам C4г групп `gates`/`s5`
ДО узла спеки `N4:gates`.

Исключения по слову владельца 13.11.2026:
- Вердикт доставки `no`: слово проводит шаг, вердикт не меняется (`question-prices.json:302-303`; P21; FR-35).
- Проверка открытого ожидания (`open-oracle-asserted`, `s5_precheck.py:90-94`: открыто до ответа, не проходит словом) —
  переопределяется отдельной идеей владельца (ожидания, помеченные как допущения); здесь только перечислена,
  **решается отдельным узлом**.

Направление по каждому семейству отдельно (какая из строк `CHECKS` какую форму отказа даёт): спека называет только класс и
перечисляет семейства, не давая по ним файла, строки и текста отказа порознь — **направление: вопрос Lead** (возвращено в
передаче).

Тест (по спеке): каждое из 7 семейств при слове человека даёт проход и строку `passed-by-person.jsonl`, либо остаётся
`known_red` с id этой находки.

Принципы и правила: P13, P15, P21; FR-4, FR-35, FR-57, FR-58; AR-9, AR-25.

Решение владельца нужно: нет (по классу решено; открытое ожидание — отдельная идея владельца).
