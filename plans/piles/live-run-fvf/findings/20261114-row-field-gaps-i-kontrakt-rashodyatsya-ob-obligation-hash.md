## Что не так

Класс фабрики: **читатель требует поле, которое контракт называет полем кода, или наоборот (AR-22, FR-11)**. Что установлено на `main` 7adcd9b6 (расхождение с записью Lead названо):

- `ai-packages/qa-factory/scripts/window_record.py::row_field_gaps` (~278) на этом дереве НЕ требует `obligation_hash`: `REQUIRED_ROW_FIELDS` (~178) держит `assertion_id`, `defect_location`, `change_disposition`, `change_basis_ref`,
  `obligation_refs`, `profile_id`; про `obligation_hash` — только строка происхождения `ORIGIN["obligation_hash"]` (~144, «the manifest row carries no `obligation_refs` to hash»).
- Требует его `ai-packages/qa-factory/scripts/acceptance.py` (~1189-1190): для окна `schema_version` 2 пустой `item["obligation_hash"]` даёт разрыв `obligation_hash:<id>`.
- Контракт `ai-packages/qa-factory/references/artifact-contract-automation.md` (~157-167) говорит: `obligation_hash` — ЕГО пишет код (`manifest_put` ставит), роль его не шлёт.
  Значит читатель требует поле, которое роль производить не может; разрыв возможен у строки, у которой нет `obligation_refs` (хеш считать не из чего).

не хватает: коммит или ветка, на которых `row_field_gaps` требует `obligation_hash` (если такой есть); Lead называет при взятии.

## Что именно менять

Выбранное направление: одна сторона следует за другой ПОСЛЕ измерения (PROJECT.md, «Как принимается изменение пакета», п. 6а): посылка про данные сначала измеряется на реальных артефактах.

1. Измерение (одна команда, результат в спеке узла): по манифестам и окнам реальных прогонов (`experiments/`, копии стенда по `docs/RUNBOOK.md` §9) — сколько строк `schema_version` 2 несут `obligation_hash` пустым, и у скольких из них
   `obligation_refs` отсутствуют. Контроль: строка с хешем находится той же командой.
2. По результату — одно из двух, выбирает дизайнер по числу: (а) хеш всегда выводим (refs есть) — читатель остаётся, контракт и `ORIGIN` называют «код пишет, пусто = код не отработал»; (б) строки без refs законны —
   читатель не требует хеш, когда refs нет (`required_when`-ключ данных), контракт это называет.
3. Тест (после измерения) — строка таблицы `ai-packages/qa-factory/scripts/tests/test_window_record.py` (если файл не быстрый — меньший, называет дизайнер): строка без refs и без хеша; строка с refs и без хеша; с обоими.
