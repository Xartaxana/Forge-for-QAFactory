## Что не так

Текст стори владелец дала обычным текстом, без markdown-заголовка. Адаптер задач `file` прочитал
`qa-factory/local-tickets/LOCAL-1.md`, взял первую строку заголовком и всё равно остановил S0 (`kind: halt`) с
четырьмя вариантами (`go on` / `retry` / вставить снова / `stop`). Первый же шаг прогона — вопрос человеку о форме
файла, который фабрика уже прочитала верно.

Класс: проверка формы входа останавливает, хотя сама нашла приемлемое прочтение и записала его (FR-4: проверка
останавливает молчаливый проход, а не осознанный; P1: код сообщает, а не останавливает).

Свидетель: `experiments/mybooks/factory-vs-free-agent/notebook.md`, «Ход прогона», 17:39:11; ответ
`answers/ticket-title-go-on.md`.

## Что сделать (предложение оператора; направление выбирает Lead)

Заголовок, взятый из первой строки, — строка отчёта и запись в стори, без остановки; стоп — только когда текста нет или
он пуст. Тест: тикет без `# ` → S0 проходит, в записи стори строка «title taken from the first line».
