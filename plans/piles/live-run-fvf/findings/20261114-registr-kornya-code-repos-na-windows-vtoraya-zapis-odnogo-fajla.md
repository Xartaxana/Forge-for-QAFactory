## Что не так

Класс фабрики: **один документ — одна запись (инвариант карточки A-2), нарушенный написанием, а не путём** (FR-41, AR-13).
Проба критика на Windows: `../SIB/docs/A.md` и `../sib/docs/A.md` записаны обе, в списке сохранённых ссылок две строки одного файла. `normal_ref` (`runtime_paths.py`) оставляет
написание корня таким, каким его дал вызывающий.

## Что именно менять

1. `ai-packages/qa-factory/scripts/runtime_paths.py` (`normal_ref`, `declared_roots`): каноническое написание берёт префикс корня из `declared_roots` (как корень объявлен в конфиге),
   остаток — как есть. Тогда оба написания дают одну запись с написанием из конфига. (Направление — слова критика: «каноническое написание брало бы префикс корня из `declared_roots`».)
2. Тест: строка в `ai-packages/qa-factory/scripts/tests/test_local_keys.py` на пару `../SIB/docs/A.md` и `../sib/docs/A.md`: одна запись. Строка исполняется там, где ОС не различает
   регистр (Windows); на канонной Linux пропускается так же, как строка про символьную ссылку того же файла (пропуск с печатью причины).
3. Порядок: после правки F2 той же записи (`normal_ref` = `relpath(place, project)`), потому что обе правки в одной функции.
