# После исчерпания раундов починки S2 у человека нет двери «вернуть работу тестеру со словами критика»

## Что не так

Критик S2 отклонил реестр требований (нет попытки опровергнуть R-12, R-9, R-5, не взят R-2), раундов не осталось.
Варианты: `go on` (принять с дырой), `restart` (освободить диспатч КРИТИКА), `retry` (человек сам дописывает форму
тестера), `stop`. Оператор выбрал `restart` со словами критика — перезапустился критик, форма тестера не изменилась, тот
же вердикт через две минуты (сама фабрика во втором вопросе: «The new session may reach the same verdict, because the
tester's handoff is unchanged»). Пришлось принять S2 с дырой.

Класс: у возвращённого состояния нет хода к исполнителю, который может его исправить (AR-25, FR-42: на каждое состояние
другой стороны — ход, называющий, кто действует; P22: дирижёр предлагает всё, что позволяет продолжить).

Свидетель: `notebook.md`, «Ход прогона», 18:10 и 18:13; ответы `answers/s2-critic-restart-as-asked.md`,
`answers/s2-critic-go-on-with-gap.md`.

## Что сделать (предложение оператора)

Среди вариантов — «ещё один раунд тестеру со словами критика (и человека)», с ценой одного раунда; `restart` критика
предлагается только когда сомнение в самом ревью. Тест: исчерпанные раунды S2 → в вопросе есть вариант раунда
исполнителю.

Принципы и правила: P13, P22; FR-40, FR-42; AR-17, AR-25.
