## Что не так

`status: incomplete`, finding: «The driver's journal holds 3 calls with no session id (the call's output was not JSON): the money
of them is in neither record». Эти три строки `state/driver-runs.jsonl` — `kind: gate_repair` гейта A (17:40:07–17:40:18 UTC,
`moves: critic_rollcall --apply-fixes, pin_cases`). Это ходы кода за 3 с, а не вызовы модели: у них нет ни сессии, ни
транскрипта, ни денег.

Сверка оператора (23:3x): 71 сессия журнала драйвера, цена CLI (последнее `total_cost_usd` сессии) — $24.32. Цена по токенам
транскриптов (`~/.claude/projects/<копия>/*.jsonl`, сообщения без повторов, тарифы `references/model-rates.json`, модель
`claude-sonnet-5-5`) — тоже $24.32, совпадает до цента. Транскриптов вне журнала три: идущий раннер `S6-qa-runner-2` (ещё не
в журнале), `/qa-doctor` и `/qa-onboarding` подготовки (17:07, 17:12 местного). Невидимых денег нет, а пометка говорит
человеку обратное (P18: одну неверную цифру как точную не показывают — но и верную как неполную тоже; FR-41: неизвестное — не
факт, известное — не неизвестное).

Побочное: наивная сумма `total_cost_usd` по строкам журнала даёт $64.34, потому что у возобновлённой сессии CLI отдаёт
накопленную цену (`634b0a20`: 0.424 → 0.455 за 2 хода). `task_price` это учитывает; любой другой читатель журнала — нет:
это стоит одной строки в описании поля.

## Что сделать (предложение оператора)

1. `task_price` считает «звонком без сессии» только строку журнала вызова модели (`kind` role / conductor / иной вызов
   CLI), не строку хода кода (`gate_repair` и подобные). Список видов — данные, не код (AR-1). Тест: журнал с
   `gate_repair` без `session_id` и с полным набором сессий → `status: agrees`, без finding.
2. Описание поля `total_cost_usd` в журнале драйвера говорит, что у возобновлённой сессии оно накопленное.
