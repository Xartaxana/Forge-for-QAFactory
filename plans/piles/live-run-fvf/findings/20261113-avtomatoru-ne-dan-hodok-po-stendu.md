# Роли не дан инструмент, который нужен её работе: у автоматора S5 нет ходока по стенду

## Что не так

Класс фабрики (P2): **роли не дан инструмент, который нужен её работе** (FR-56 «роли даются только нужные инструменты»; P14;
FR-11 «если контракт требует поле от роли, инструмент, на который роль указана, должен уметь его произвести»).

У автоматора S5 нет команды ходока или рекордера: раздел «Tools» его карточки (`agents/qa-automator.md:65-74`) ни одной не
называет; карточка команды ходока строится только для первого взгляда и ручного прохода S6 (`scripts/brief_pack.py:3702, 4308`).
Когда первый взгляд пуст или ошибся (см. находку `20261113-pervyj-vzglyad-ne-dohodit-do-avtomatora.md`), автоматору нечем
посмотреть стенд самому.

Факт из разведки t-448: до 0.11.0 первого взгляда не было; автоматор работал по карте тестового репозитория, которую даёт ему
бриф, — существующие тесты области, page objects, помощники (`scripts/brief_pack.py:2650-2677, 3043`) — и расширял page objects
проекта. `agents/qa-automator.md:55` называет «your live check» источником, но инструмента для него не дано.

Слово владельца 13.11.2026: «это правильно, но для нового функционала их там может не быть».

Уточнение: `selectors` профиля (находка FV1-18) — это ВЫБОР ТЕСТОВ раннером (`scripts/profile_contract.py:343-357`), а не
локаторы страниц; их нельзя смешивать.

Слово владельца 13.11.2026: «Селекторы заполняет первый взгляд, но даже если их нет, автоматор не должен останавливаться, если
их не хватает или они не верные, он может сам посмотреть на стенд».

## Что менять

Автоматор получает ходока фабрики (`scripts/walk_session.py`; улики пишет код, P26), чтобы самому посмотреть стенд, когда
первый взгляд что-то не даёт или неверен; отсутствие селекторов его никогда не останавливает. Существующие page objects остаются первой дорогой; для НОВОГО функционала,
где page object нет, локаторы берутся из первого взгляда, а чего там не хватает, автоматор смотрит сам ходоком.

Связи: находка про первый взгляд (B2, тот же прогон), FV1-18 (контракт селекторов: отсутствие не стопорит прогон).
Тест: бриф и карточка S5 называют команду ходока; строка «Tools» и карточка команды берутся из одного источника, как у ручного
прохода.

Принципы и правила: P14, P26; FR-11, FR-56; AR-11.
