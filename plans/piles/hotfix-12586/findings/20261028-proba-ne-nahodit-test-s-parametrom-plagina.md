## Класс

Проверка ждёт точного id, а производитель отчёта (плагин pytest) добавляет параметр, о котором роль не знает: проверяется то, чего роль не ожидает (FR-38, AR-10; находка forge F6-51 о стыках). Сосед — общие читатели «того же теста» (HF3), сверка — по оси карты симметрий.

## Направление

Запрос без параметра и одна строка `<func>[p]` — эта строка; несколько — судится каждая, убит только если убиты все; ни одной — `not_executed` с перечнем id отчёта (≤ 5). Ключ стыка — записанный junit прогона через читатель пробы. Узел HF4-12, диспатч t-1474.
