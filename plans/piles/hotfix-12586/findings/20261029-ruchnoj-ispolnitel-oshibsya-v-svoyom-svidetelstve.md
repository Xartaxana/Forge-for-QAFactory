# Ручной исполнитель S6 записал «упал» вопреки своему свидетельству; перепроверка не может переоценить готовую попытку

id: — | кучка: `hotfix-12586` | от: прогон TP1-12586 на 0.10.5, `testproject1-dev-010`, 29.10.2026 | приоритет: П1 (0.10.7, решение Lead) | кандидат наверх: нет

## Что наблюдалось

1. `S6-qa-runner-2` (manual-agent, 37 мин) записал TC-007 failed: «refused move shows only toast Access denied». В той же попытке
   `work/evidence/manual/TC-007/a9/006-read--toastify.txt` и скриншот `007` несут строку причины «You do not have sufficient
   permissions to access the project». Ошибку поймал аналитик S7 (`work/handoffs/S7-qa-failure-analyst-1.help.yaml`): ни один закрытый
   вердикт триажа не подходит (APP_BUG — противоречит свидетельству, TEST_BUG — отдаёт ручную проверку автоматору).
2. Доработка `S6-qa-runner-3` (`repair_verify`) — переоценить Then 1 по готовому свидетельству — встала через 3 мин: `manual_evidence.py
   build` отказывается пересобрать уже записанную попытку a9, а новая попытка a10 не имеет данных (интеграция удалена): «Setting not
   found». Второй агент того же диспатча прошёл весь сценарий заново (13 мин), отчёт пишет «It passed on a re-run only after the runner
   misread its own evidence» и отдаёт TC-007 человеку.

## Класс

(а) Вердикт ручной проверки пишется словами исполнителя без сверки с собранным им текстом страницы — сверка Then с `*-read-*.txt` не
обязательна. (б) У перепроверки ручного кейса нет хода «переоценить готовую попытку без повторного исполнения»: только полный повтор
со свежими данными, а их засев не повторяется.

## Что нужно

1. Форма ручного исполнителя: для каждого Then — цитата из захваченного текста/ответа, на которой стоит вердикт; `fail` без цитаты,
   противоречащей Then, — отказ формы.
2. `manual_evidence.py` — ход «re-judge»: новая оценка по существующей попытке (новый `record` с отсылкой к попытке, без пересборки).
3. Вердикт аналитика «вердикт исполнителя противоречит его свидетельству» — закрытое значение триажа с возвратом исполнителю на
   переоценку, без вызова дирижёра.
