## Класс

Сборка запроса `--mine` по-прежнему зовёт collect через `poetry run pytest --collect-only` (у проекта conftest при импорте ходит на
стенд, «Fetching providers») даже когда строка манифеста и маркер теста уже называют файл и функцию; после прогона — синхронная
работа (дашборд, свод), не нужная роли для следующего хода. Цена — чистое трение (P11, FR-51, FR-55, AR-12).

## Направление

1. Сначала замер: `run_suite` печатает и пишет в запись прогона время фаз (сбор запроса, collect, проба, pytest, после) — одно
   поле `phases_s`; без него следующий разбор снова «оценка» (FR-28).
2. Collect не зовётся, когда id известны из манифеста/маркеров и файл существует; проверку id делает сам запуск pytest
   (`not found` → отказ с дверью, не тихий проход; AR-28). Повтор `--mine` того же набора на тех же байтах файла берёт id
   прошлого запроса.
3. Работа после прогона, не нужная роли сразу (пересборка дашборда), — после возврата ответа или в фоне.
4. Тест: `--mine` на фикстуре с известными id не вызывает collect (счётчик вызовов); неизвестный id → отказ с дверью.
