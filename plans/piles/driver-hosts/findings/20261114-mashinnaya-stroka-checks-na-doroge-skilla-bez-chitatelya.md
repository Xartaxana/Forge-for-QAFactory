# Машинная строка `checks: [...]` в выводе `story_step finish` на дороге скилла остаётся текстом: её снимает только `Driver.finish`

id: — | кучка: `driver-hosts` | от: черновик носителей P1-v N8 (`docs/tasks/specs/20261114-p1v-n8-carriers-draft.md`, раздел «Noticed, not widened», пункт «Axis 34 analog») | приоритет: П3 | кандидат наверх: нет

## Что не так

Класс фабрики: **производитель печатает всем, читатель есть у одной дороги (AR-22, SIBLING_MAP ось 34)**. `ai-packages/qa-factory/scripts/story_step.py::_gate_refusal` (~2062-2064) последней строкой отказа выхода печатает JSON-список id сработавших
проверок (`detector_verdict.CHECKS_LINE_PREFIX + json.dumps(...)`) для КАЖДОГО вызывающего. Читатель один: `ai-packages/qa-factory/scripts/driver_dispatch.py::Driver.take_checks_line` (~895, зовётся из `Driver.finish`, ~861) вынимает её до того, как текст читает роль,
дирижёр или `finding_key`. На дороге скилла (оркестратор запускает `story_step.py finish` сам; `ai-packages/qa-factory/skills/qa-story/SKILL.md`) строку никто не вынимает: она приходит оркестратору текстом, не названная и не прочитанная.
Позиционный инвариант производителя («после неё ничего не печатается») при этом остаётся верным.

## Что именно менять

Направление Lead в записке не названо: **рекомендация ниже взята до слова Lead (развилка обратимая, узел исполним по ней)** — строку печатает только тот, кто о ней просит.

1. `story_step.py finish`: новый необязательный флаг `--checks-line`; без него `_gate_refusal` строку не печатает; с ним — последней строкой, как сегодня (позиционный инвариант тот же).
2. `driver_dispatch.py` (вызов `story_step finish` из `Driver.finish`): передаёт `--checks-line`; `take_checks_line` не меняется. Производитель и читатель — в одном коммите (AR-22).
3. Пустое и неизвестное: без флага вывод — сегодняшний БЕЗ последней строки; флаг при чистом выходе (нет отказа) ничего не печатает; неизвестный флаг — отказ парсера как у соседей.
4. Тесты — строки таблицы: `ai-packages/qa-factory/scripts/tests/test_then_remainder.py` (~856: хвост отказа без флага не заканчивается `checks:`, с флагом заканчивается) и `ai-packages/qa-factory/scripts/tests/test_driver_stop_record.py`
   (`take_checks_line_cases`: вывод драйвера содержит флаг). Быстрые файлы; дизайнер сверяет по `test-layers.json`.
5. Вариант Б (если Lead против флага): текст скилла называет строку («последняя строка `checks: …` — машинная, её не читают»). Хуже: читатель — дисциплина, не код (P27: данные — код).

Принципы и правила: AR-22, AR-18; P27; FR-14 (форма вывода — контракт).
