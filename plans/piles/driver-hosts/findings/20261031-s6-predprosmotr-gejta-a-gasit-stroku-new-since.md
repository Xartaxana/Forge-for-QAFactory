# Предпросмотр гейта A стирает строку `new since you last saw this list` для настоящей цитаты

id: — | кучка: `driver-hosts` | от: узкий критик S6 0.10.7 (`docs/tasks/specs/reviews/r0107-s6-skill-path-critic.md`, N-8), фикс-раунд t-414, 31.10.2026 | приоритет: П3 | кандидат наверх: нет

Что не так / что сделать: на пути скилла каждая печать `gate_brief.py --gate A` до решения человека перезаписывает запись «что показано» (`state["shown_attachments"]`). Проба критика: первая печать содержит строку `new since you last saw this list: ...`, вторая (настоящая цитата человеку) её уже не содержит, потому что первая записала файл как показанный. Файл по-прежнему в списке, теряется только пометка «новый». Правило фикса t-414 (после решения запись не меняется) времени ДО решения не покрывает: предпросмотр до решения остаётся остаточным риском; долг по файлу от него не страдает (запись считается только с решением и только по названным именам).
Варианты: принять остаток (одна строка в пачке; цена: человек иногда не видит пометку «новый» на повторной печати до решения); или хранить в записи отдельно «что показали человеку» и «что напечатал предпросмотр» (нужен сигнал «это цитата», которого между stdout и чатом нет: флаг `--shown` ничего не доказывает и стоит байтов устава). Рекомендация критика: принять остаток.

Свидетель: узкий критик S6, N-8 (строка 65): проба «первая печать — строка есть, вторая — нет».

Принципы и правила: P1, P3; FR-4, FR-41; AR-28.

Решение владельца нужно: нет (решает Lead: принять остаток).
