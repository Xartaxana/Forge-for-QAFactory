# Запрет дублей в правилах не работает: детектор S5 ловит только точную копию тела в файлах своего окна

id: — | кучка: `test-code-quality` | от: прогон TP1-12586 на 0.10.5, 29.10.2026 (критик t-1577 D-4, D-5, D-6; владелец: «мы писали что нельзя дублировать код, но не помогло, надо что-то ещё сделать») | приоритет: П1 (0.10.7, слово владельца) | кандидат наверх: нет

## Что наблюдалось

- Два способа читать проектную интеграцию по id в одном диффе: `_rows/_row_by_id` в тесте и новый метод `integration_utils.py:177-192`.
- В page object `should_have_selected_project` повторяет существующий `should_show_project_display_name`; `should_show_project_change_modal`
  заново строит локатор при существующем свойстве `project_change_modal`.
- Три копии `try/except HTTPError → (status, text)` в тесте; `_put_project(r, t)` ≡ `_put_changes(r, project_name=t)`; сборка MS Teams
  дважды (тест и conftest).
- Тот же класс у первого прогона (t-1207 Q-3: `change_project` рядом с `select_project`, `wait_until_settled` ≈ `wait_for_page_load`).

## Почему правила не помогли

Запрет записан в `test-code-patterns.md`, rubric критика кода и брифе автоматора — это текст, его соблюдение никто не измеряет.
Единственный код — `s5_precheck.py:1928-1940`: находка, только если у двух функций **точно одинаковое** тело (`ast.dump`), и только среди
файлов **окна**. Он не видит: (а) почти-копии (другие имена переменных, аргументы, порядок), (б) копию существующего метода харнесса или
page object, (в) повтор блока внутри функций (три `try/except`), (г) копии между окнами одной истории. Критик кода смотрит окно, а не
харнесс, и дубли против существующего кода пропускает. TQ1-7 (тропа поиска аналога) — П2, в релиз не входил.

## Что нужно

1. **Детектор почти-копий на пути S5** (подход нашего `tools/dup_ratchet.py`): нормализованная форма AST (имена и литералы обезличены),
   окна из N операторов — для (а) и (в); сравнение **каждой новой функции диффа истории** (все окна) с функциями тех же модулей харнесса и
   их page object/utils из карты репозитория (`work/briefs/repo-map-*.md`) — для (б) и (г).
2. **Отказ, а не подсказка**: найденная копия — находка выхода S5 с именем существующего кода и дверью «оставляю: <чем существующее не
   подходит>» строкой манифеста; критик кода читает эти строки (P15: дверь есть всегда).
3. **До работы** (FR-38): бриф окна несёт список существующих хелперов и методов page object затронутых модулей; манифест — `introduced_helpers[]`
   с полем «искал аналог: где / нашёл» (TQ1-7, поднят до П1 0.10.7).
