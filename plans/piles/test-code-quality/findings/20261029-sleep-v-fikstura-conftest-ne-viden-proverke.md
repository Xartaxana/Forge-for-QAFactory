# `sleep` в фикстуре `conftest.py` не виден проверке запахов S5: ловит только критик, после пробы — лишний раунд

id: — | кучка: `test-code-quality` | от: прогон TP1-12586 на 0.10.5, `testproject1-dev-010`, 29.10.2026 (вопрос владельца: «почему у нас вообще фикстура была с time.sleep(2)? Мы же запрещали») | приоритет: П1 (0.10.7, решение Lead) | кандидат наверх: нет

## Что наблюдалось

Автоматор окна 2 (`agent-a3ab1c48a50709489.jsonl`, 14:12 UTC) дописал в `testproject1_test_harness/tests/integrations/conftest.py`
фикстуру `second_user_admin_of_first_project` с `time.sleep(2)` вместо ожидания роли. `s5_precheck` окно пропустил. Критик
поймал это (F-2) только после того, как проба TC-006 упала в setup с 403. Итог: доработка вне контроллера, перепроба, устаревшие прогоны
всех трёх тестов окна (фикстура общая) и остановка фабрики (HF8-15).

Запрет есть в трёх местах:
- `references/test-code-patterns.md:106` — «wait from core, instead of sleep»;
- `references/code-review-rubric.md:60` — измерение 3 «no sleep»;
- код: `scripts/s5_precheck.py:1921-1926` — запах `sleep-…`.

## Класс

Код-проверка смотрит не туда: `check_smells` (`s5_precheck.py:1861-1862`) берёт тест и фикстуры, НАЗВАННЫЕ его аргументами, только
из ТОГО ЖЕ файла (`pyfile.functions` / `pyfile.fixtures`). Не видны:
- фикстуры из цепочки `conftest.py`, хотя читатель этой цепочки в том же файле уже есть (`conftest_fixtures`, `:2007`);
- фикстуры фикстур (транзитивно).

Комментарий у `:1859` сам называет причину правила («a fixture the test depends on is part of the test: … TP1-15045»), но
правило покрывает только один файл. Тот же охват у остальных проверок этого цикла (`_assert_nodes`, сравнения тел, подсчёт текстом).

Роль при этом знала запрет только из справки: требование не стоит в форме перед работой (FR-38). Проверка, которая могла бы
остановить запах до прогона, его не видела (FR-17: инструмент для проблемы подключён не везде, где она встречается).

## Направление

1. Охват `check_smells`: тест + транзитивное замыкание его фикстур по цепочке `conftest.py` (один разборщик с `conftest_fixtures`,
   AR-13); фикстуры проекта, которые окно НЕ меняло, — без находки (запах чужого кода — не дефект окна): только изменённые/новые в
   диффе окна функции.
2. Опрос с интервалом (`while … sleep(1)` с потолком) — не запах, если ждёт условие; голый `sleep(N)` перед действием — запах.
   Граница — в тексте находки и тесте.
3. Строка «ждать условие, не секунды; фикстуры в conftest — тоже код окна» — в форме/брифе автоматора до работы (AR-10).
4. Тесты: `sleep(2)` в новой фикстуре conftest, нужной тесту через другую фикстуру, — находка; опрос с потолком — нет; `sleep` в
   неизменённой фикстуре проекта — нет.
