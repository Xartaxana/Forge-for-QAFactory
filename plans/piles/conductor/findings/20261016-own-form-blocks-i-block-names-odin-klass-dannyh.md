## Что

C4-3 (t-888) вынес в данные имена блоков, которые читает код (`keep it local`, `executor unavailable: <profile>`, `story budget`),
с указателем на читателя. Но в `waiver.py:361-365` остаётся литеральный кортеж `OWN_FORM_BLOCKS` (`question threshold`, `mode switch`,
`stand not confirmed`, `stand login missing`) — тот же класс: имена, на которые действует читатель (`story_step` читает `mode switch`,
…), только без указателя на читателя и без проверки загрузчиком. Константы импортируют их писатели (t-722 §3.2 шаг 2, N5), поэтому
свёртка — не удаление, а строки таблицы плюс указатель: константа остаётся именем для импорта, таблица — единственным местом, где
сказано, кто имя читает и на какой стадии.

Что сделать: строки `block-names.json` для четырёх имён с читателями (`stage`-колонка по читателю), `OWN_FORM_BLOCKS` строится из
таблицы или проверяется против неё тестом (одно место, FR-13/FR-17); пины: имя из кортежа без строки в таблице — красный тест.

Свидетель: `docs/tasks/specs/reviews/t-894-t-888-c4-3.md` F-4; `waiver.py:361-365`, `:550` (`_is_own_form`).

Принципы и правила: P10, FR-13, FR-17, FR-54.

Решение владельца нужно: нет.
