- New config key `dispatch.parallel_windows` (whole number, 1 or more, default 3): how many S5 automation windows may run their role sessions at once. Windows run in parallel by default; a project may set 1 (or 2) to run them serially or fewer at a time. A config without the key reads 3; a value that is not a whole number of 1 or more reads 3 with one `note:` line and never stops a run. The template carries the key; the scheduler that reads it lands separately.
