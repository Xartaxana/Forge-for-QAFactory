- A session that only ever ran the collect skill or environment maintenance now counts as factory work everywhere it is asked: the guard's session check, the cost capture (`likely_factory` and `has_factory_activity`), and the dashboard's and the metrics' fallback for a cost file written before that field existed all call ONE predicate, `activity_capture.is_factory_activity` (a dict entry whose `type` is a string of `REAL_FACTORY_TYPES`, every named activity type except `unclassified`); a junk type in an activity file (a list, a dict, a number) reads as "not factory work" instead of raising. The capture stamp moves to `capture-0.10.8`: every existing cost file of an older stamp is reclassified as an older capture logic on its next read and recaptured once by the stale pass (one recapture per file, its price), so collect and environment-maintenance sessions captured before this release stop reading as "not factory work" and get a per-request ledger.
