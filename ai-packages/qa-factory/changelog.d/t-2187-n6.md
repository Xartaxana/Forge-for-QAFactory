- New `bug_neighbours.py --task-root <task root>` prints the neighbourhood table of an S7 triage: the failures, observations, triage rows and drafts that share a requirement, a case, a test file, a code line (the same normaliser `same_location` uses) or an equal seen text, with the shared value. It is a hint for the failure analyst and the scribe, never a verdict: it reads only, writes no file, and says nothing about whether two units are one cause. A source it cannot read is named as unreadable instead of reading as an empty table. The S7 triage brief carries the table cut to `brief_neighbours_max` groups (`references/place-answers.json`) with the command for the rest, and the failure analyst's and the scribe's command cards list the command.
