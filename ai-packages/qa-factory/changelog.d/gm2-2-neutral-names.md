- The package no longer carries an agent CLI of its own: `references/external-agent-calls.json` ships an empty `forms` list and `cost_capture.py` has no built-in form. A project that calls an external agent from a session adds a row under `cost.external_agent_forms` in `qa-factory/config.json` (same shape as before); until it does, such a call is a shell command like any other and the price lists no form it counted. A recorded call key with no form marker is now reported as a form with no row, never lost.
- The default sign-in recipe for a UI stand no longer names a browser storage key or a session cookie: `login.ui.landed.session_cookie` is empty, so a login is proved by the sign-in field being gone. A project that wants the stronger proof names its cookie (and any storage keys to preset) under `manual_capture.login.ui` in its config.
- The names inside the package's examples, fixtures and tests are neutral (Test Project 1, TP1-<number> keys, example hosts, Test User N): a data change only, no behaviour of a role or a gate changes.
