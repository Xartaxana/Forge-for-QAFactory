- `probe_by_code.py`: the probe's report rows are bound by ONE rule keyed by the contract's shape. A contract with a `file` is read by `red_sandbox.selection_rows` as before; a contract with no `file` (a pytest contract) or no contract is read by `red_sandbox.matching_rows` against the requested node, and every matching row is judged (a plugin-parametrised `test_x[chromium]` row is the node's, `func[webkit]` never matches `func[firefox]`, none is picked silently). A report with no row of the node says what it held. The frame reader is asked for every reader the factory knows (`reporters.READERS`, so `reporter: pytest` is read) with the pytest command read from the request's argv once. A raw row that holds a failure or an error problem is judged `failed` / `error` even when a `<skipped>` child outranks it in the row's own status. `judge_detector` is renamed `judge_probe_row` and `_judge_detector_rows` `_judge_rows`; the behaviour of the row judge is unchanged.
