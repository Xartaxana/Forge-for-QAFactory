- Every report section heading has one home in `grammar` (`PROVEN_HEADING`, `LEFT_WITH_YOU_HEADING`, `GATE_B_HEADING`, `APPENDIX_HEADING` and the rest); the report writer, the block renderers and the report checks read it from there, so no rendered report changes by a byte. The report's appendix has one reader, `report_facts.appendix_span` / `appendix_body`: the appendix is the section from its heading line to the next `## ` heading or block marker, outside code fences. A fenced or mid-line mention of `## Appendix` no longer hides a forbidden id or prose from the report checks, and a requirement named only in a section after the appendix is reported missing from the appendix table, not counted as present.
