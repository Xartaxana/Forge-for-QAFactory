- The readiness record now says so when a project's config declares no test surface at all (no capability word, no environment naming a surface, `profiles` absent included): `surfaces` carries an `undeclared` note that the default road was taken, instead of staying silent. A project that declares a web or API surface, or a surface the factory drives, is unchanged byte for byte.
- A surface the factory has no driver for (a command-line or desktop application, a word the table does not know, native tests with no stand) is now the agent role's to try by hand first: its readiness entry says `hands: role` and its words say that only what the agent could not do is left with a person; before, the cases were handed to a person untried.
- A stand that names no address and does not say it runs in-process still passes the environment check as before, but the readiness note now says it was taken as in-process and nothing was probed; a stand that declares itself in-process keeps its note unchanged.
