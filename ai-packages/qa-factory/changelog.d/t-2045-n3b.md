- `probe_by_code.py`: ONE row judge for every language (t-2064 N3b). A Python test now carries `language`, `entry` and `tail` in its spec and its run goes through the same road as any other language (`_judge_rows` over the runner's rows); Python's own judge (`verdict_of`, `_judge_row`) is removed. `judge_probe_row` is a short sequence of steps: a failed row whose failure text holds the probe's own marker is `intended_failure`, `proved_by: marker` - the only proof the code writes; a pass is never proved (a pass of a check chosen by `--at` or the manifest's id that does not lie in the located body of the test is `incomplete`, never `no_failure`); a failed row with text and no marker is `incomplete`, `cause: judgment`, with the place (`location_hit`) and the stack frames among the facts for the code critic. The place of a failure and the library's wording (`fires_as`) no longer prove anything and `wrong_location` is no longer written by the probe (the alternative probe keeps its own judge); an old record's `proved_by: fires_as` still reads. A null `fires_as` never crashes.
