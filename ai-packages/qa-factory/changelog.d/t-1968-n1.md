- The mutation probe of a test that is not Python now proves "the broken check fired" by a fact the factory controls: the inverted statement carries a message holding `qa-probe-<token>`, joined at run time from two pieces so no source line or code frame holds it contiguous, and a failed run whose failure text holds that exact token was thrown by that check (`proved_by: marker`), whatever the library's wording and whatever site the frame names. How a message attaches to an assertion form is data (`assertions[].message`, `assertion_probes.<language>.marker_expr` in `references/detectors.json`; xUnit `True`/`False`, NUnit `That`/`AreEqual`/`AreNotEqual`, JUnit 5 and 4, AssertJ `as`, Playwright `expect`); a form that takes no message, or a file whose library cannot be told, keeps the plain inversion and the wording table (`proved_by: fires_as`) as before. The token of another run, a token only in an echoed source line or a system-out, a passed row and an error row are never a proof.
