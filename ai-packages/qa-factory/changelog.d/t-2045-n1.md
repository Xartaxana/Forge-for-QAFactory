- `probe_by_code.py` reads ONE target for a test of any language, in this order: `--at`, then `--oracle`, then the manifest row's `assertion_id` (`<file>:<line>`), then the first check. `--at` is no longer refused on a Python test, and it takes `<line>` or `<file>:<line>` (the spelling of `assertion_id`); a check is found by its line in the whole file, so a check in a helper or a page-object method needs no declaration. A probe whose id stands on the second check of a test no longer breaks the first one.
- A target line that holds no check of a form the factory reads is refused before a byte is written, naming the nearest check below it, the helper the line calls, and the two doors (`--at <line>`, correcting the row's `assertion_id`). A target file that is absent or outside the test tree is refused for every language (an absent `--oracle` file no longer falls back to the test). The probe record's `target` gains `source`, and the plan's `mutation_detail` gains `target_source` and `target_outside_body`.
