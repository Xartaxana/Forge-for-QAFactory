- A document reference on a decision row (`doc:<path>[#<anchor>]`) is now checked as a relative path: `doc:https://x` and a drive path are refused because of the `:`, a leading `./` and an empty `#` are dropped, and the refusal says the form to write instead. A refusal of the decision registry's `add` and `resolve` commands is now one line with exit code 2 (as `add-finding`) instead of a traceback, and a marker file given to `resolve` is judged by the same relative-path rule (no drive, no `:`, no leading `/`, no `..`).
