- The controller can now let a second S6 manual walk start beside a running one, so parallel walkers have a place to run. Only the driver asks for it, and only for manual runner dispatches whose cases do not overlap, whose accounts differ (two walkers never sign in as the same account; a guest is an account too) and whose number stays within the new `manual.walkers` key (default 3, `1` runs one walker at a time as before; a value that is not a whole number of 1 or more reads 3 with one note line). A dispatch that carries no account is an unknown account and nothing is started beside it. Every other second start keeps the old refusal word for word. A stopped walk resumes beside its running siblings, and the S6 stage stays `running` while any walk works. Onboarding asks once how many manual walk-throughs may run side by side.
