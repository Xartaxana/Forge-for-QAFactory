- Project knowledge, phase 0 (PK0-5): the stand's default login is asked only when the story needs it, by ONE rule that gate A and S6 both read (`gate_preflight.default_login_needed`). It is needed when a case declares the default account, the plan automates something, a manual case names no account, an executed case seeds data, or an executed manual case names a role whose account is not recorded on the chosen stand (the runner would create it as the default); it is also needed whenever the plan, a case or the registry cannot be read. A role the person said is not a role of this product (its cases are carried as not run) no longer asks for it. When it is not asked, gate A says so in one line instead of listing missing login keys, and S6 does not read the default account. S6 also reads a role's account on the chosen stand only, and refuses with the reason when no stand is chosen (the reserved `env:` / `created:` / `default` accounts need no stand and are not refused for it).
