- One cause, one bug report: the bug reporter's charter now says defects with one confirmed cause are one report listing every manifestation, each with its own steps and failing test, and a suspected shared cause is a link between separate reports. `artifact_producer.py validate` reads the source draft of a bug through the one draft reader; when that draft has two or more manifestations the bug file must list every case in `cases`, carry `## Cause` and `## Manifestations`, and name in the latter each manifestation's case and its red test command or the reason there is none. A draft that cannot be read is one refusal that names the door; with no task root the check is not run and the validator says so instead of passing it. A draft with one manifestation, or none, files exactly as before. The bug-file section of the key page names the two new sections.
