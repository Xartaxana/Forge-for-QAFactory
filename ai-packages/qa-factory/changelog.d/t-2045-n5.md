- `probe_by_code.py`: ONE hop out of a test body that holds no check now works for every language, through data. A test whose body asserts nothing is followed into the helper it calls by name (calls read in source order from the code with strings and comments hidden), in the test's own file and then in the files it imports from the test tree; the first declaration holding a check is the oracle, and the probe's note names it as before. TypeScript and Java read their imports from the new optional `import_forms` rows of `references/detectors.json` (`{pattern, resolve: relative | dotted, suffixes}`; a Java static member or nested class resolves to its class file); C# has none, so only the same file is searched and the note says so. `helper_declaration` for TypeScript now also reads an arrow const with a block body and a class (page-object) method, and never reads a call, a keyword block or an anonymous arrow as a declaration. A file outside the test tree is never hopped into and never mutated; an import that names no file is skipped with a note; a name declared twice in one file with a check in one of them is a refusal that names the lines; a check two hops away is a refusal whose door is `--at <file>:<line>`; a fixture handed in by `test.extend` is not followed, and the refusal for a body with nothing to hop into now names the same door. Python keeps its conftest chain and fixture parameters.
- `probe_by_code.py` gains `declared_once(data, suffix, function)` and `enclosing_declaration(data, reader_entry, line)` (pure readers of the same data), and `probe_debt.py` replays a probe that mutated a helper in any language by `declared_once` instead of requiring a hand-named helper outside Python; a language with no entry gives a reason naming the data gap.
