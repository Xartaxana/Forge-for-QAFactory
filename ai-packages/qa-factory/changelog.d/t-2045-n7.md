- `probe_by_code.py --mutation expected` is removed: it replaced the expected literal of a comparison with another one, which proved nothing the inversion does not, and only Python could run it. The flag is still accepted by the parser and is refused for every language with one sentence and the door `--mutation invert`. A stored record whose mutation was `expected` still reads, and `probe_debt.py` replays it as `invert`; any other unknown stored mutation is refused as before.
