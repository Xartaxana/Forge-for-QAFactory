- `probe_by_code.py`: a test's spec now names its reader (`reader: "ast"` for Python, `"table"` for the other languages), and the places that asked whether a spec had a `language` read that key instead. A Python probe plans the same detail keys as the table's plan (`language: "python"`, `message_marker`, `message_form`, `statement_inverted` and the rest), and the factory's own marker `qa-probe-<token>` now travels as the inverted assert's message, an expression joined at run time (`'-'.join(['qa-probe', '<token>'])`), so a traceback that echoes the source line never holds the contiguous token. `references/detectors.json` gains `assertion_probes_ast` (Python's marker expression and frame grammar, read only through `assertion_detectors.ast_entry`) and an optional `frames_deepest` (`first` / `last`; unknown when absent) on the table entries, read through `assertion_detectors.frames_deepest`.
