- The exit gate's state lock and the project-decisions lock are now OS file locks (the package's one file-lock helper): a hook or writer killed while holding one no longer leaves the gate or the registry busy for the rest of the run, and a lock file is never deleted. A refusal names the lock and, where recorded, the holder. The project-decisions lock moved to the file `qa-factory/state/project-decisions.lock`; an older leftover `.project-decisions.lock` folder is listed and never blocks.
