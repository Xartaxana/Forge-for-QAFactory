- New step `end-session` (browser surface, in a `ui` call and in a walk session): it deletes every cookie of the current actor's browser context and leaves the page open, as for a person whose session ran out, so the next request of the page goes without the session cookie. The answer says how many cookies were deleted; an actor with none (a guest, one not signed in, a second `end-session` in a row) gets `0 cookies` said aloud, not a failure. No cookie name or value is stored. A device has no such step and its steps file naming it is refused with the device's own list. A step that takes no argument now refuses an extra one with the door `write <step> alone on its line`.
