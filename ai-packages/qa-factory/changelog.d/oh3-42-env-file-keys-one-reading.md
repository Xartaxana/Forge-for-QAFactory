- The names an env file declares (`project_inventory.env_file_keys`, used by the source inventory and the config contract) now come from `env_probe.parse_env_file`, the one reading of an env file, instead of a second parser: a name on the first line after a byte-order mark is now found (it was missed), a line `export =x` no longer yields the name `export`, and an upper-case `EXPORT A=1` is no longer listed as the name `A` (shell `export` is lower case; the one reading keeps `EXPORT A` as the name, which is not a key name). `machine_facts` drops its own second strip of the `export ` prefix.
