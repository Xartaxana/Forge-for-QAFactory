- When a run with parallel windows starts to drain (a window failed, or the boundary limit was reached), a window that was waiting for a sibling's running session no longer starts its own session after the drain began: it stops there with its window left open for the next entry, instead of holding the person's question behind a whole extra session. The window whose own launch reached the boundary limit still launches, and a window with nothing in its way is not affected. With one window nothing changes.
