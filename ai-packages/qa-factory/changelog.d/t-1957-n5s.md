- The driver walks the manual half of S6 in lanes: up to 3 cases that share one account set (`controller.walk_lanes`, one function for the driver, the `story_step.py start` door and the progress line; guest cases form one lane, a case whose request cannot be read walks alone). Before a lane the driver makes sure a run report exists, builds the app card and opens a walk session for the lane's account; after the walker ends it closes the session, builds the case records from the walker's result records, runs `finalize_task.py`, writes the form's values and a timing end line. `run_role` takes a new keyword `after=` that runs once the role is over (also when it crashed or returned nothing) and before `bind`, `handoff` and `finish`; `resume_role` reopens a dead walk session before the resume words. A record the build refuses is walked once more in the next lane and then closed `left_unchecked`. A lane whose session cannot open runs on the recorder as before.
