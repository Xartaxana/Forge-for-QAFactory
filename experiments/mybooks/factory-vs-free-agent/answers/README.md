# Ответы владельца продукта — одни слова обоим плечам

Правило (PROJECT.md «Прогоны и эксперименты», RUNBOOK 9.2.4): на один и тот же вопрос оба плеча получают ОДНИ И ТЕ ЖЕ слова.
Набор вопросов у плеч разный, поэтому ответ выбирается по смыслу вопроса, не по его номеру. Файл ответа кладётся сюда при
первом появлении вопроса (`<тема>.md`), и второму плечу на тот же смысл уходит тот же файл.

## Слова, которых НЕТ

Девять мест «решать владельцу продукта» (карточки 2, 4, 5, 6, 7, 8, 19, 20, 22 таблицы правды) владелец ещё не решала.
На вопрос о таком месте оба плеча получают один текст (файл `no-decision-yet.md`):

> There is no decision on this yet. Record it as an open question for the product owner, with what you saw, and go on.

Вопрос, которого нет ни здесь, ни в заготовках, оператор закрывает по RUNBOOK 9.1(a): самое консервативное прочтение, не
останавливающее прогон, с пометкой «мои» в журнале вопросов тетради — и те же слова второму плечу.
