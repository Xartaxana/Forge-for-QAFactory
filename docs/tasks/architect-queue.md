# Очередь для Архитектора

Вопросы, которые Lead (или владелец) отдаёт Архитектору (Fable): архитектура новой идеи, компромисс процесса,
конфликт правил, который Lead не решает, эскалация правила 6 выше Opus. Читает сессия Архитектора при старте
(`PROCESS/ARCHITECT_START.md`, шаг 3); строки `- [ ]` считает строка SessionStart. Пишут Lead и владелец.

Форма строки (одна на пункт):
`- [ ] <YYYY-MM-DD> <task_id|—> <вопрос одной строкой> (от: Lead|владелец)`
Вычёркивает Архитектор:
`- [x] … — сделано: <D-nnnn | хэш | t-nnn | ответ одной строкой>`
