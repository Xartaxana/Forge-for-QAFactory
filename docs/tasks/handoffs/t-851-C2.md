2. Green prints exactly `run <id> success: nothing failed` (one line); unfinished prints the normal run line with the status in the conclusion slot; no-failed-job prints the run line then `<conclusion>: no failed job`.
3. `latest` with no runs prints `(no runs)` exit 0 (like `pipelines`).
4. Failed = conclusion `failure` or `timed_out`, for jobs and steps.
