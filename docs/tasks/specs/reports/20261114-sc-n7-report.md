## What changed
`append` walks all independent checks into a `problems` list and raises ONE `ValueError(PROBLEM_JOIN.join(problems))`, `PROBLEM_JOIN = "; "`. No join form existed in the file, so this is new. The helpers (`_closed`, `_nested_keys`, `_check_probe`, `_judge_refs`, `_link`, `_origin`) append their sentences instead of raising; every sentence is byte-identical to before. A one-problem line gives today's message.

Collected together, in walk order: excluded keys (each once) and unknown keys; keys a withdraw does not carry; keys that do not belong to the op; `kind`; every `probe` problem (nested keys, method, runs, reproduced, safe_to_break); `verification_status` (closed list, then the no-probe rule); oracle (confirmed / closed list / person_confirmed); each missing required text; question and owner_role; missing_prerequisite; `refs`; `evidence_refs` absent or empty; every evidence ref (nested keys and the `evidence_ref_issue` sentence, per ref); `origin` problems; link problems (`corrects`/`withdraws` missing, nested keys, no reason); target already has a line; named line not active; correction changes the target; code-set fields.

Stoppers, refused alone and first (checked before everything else, in this order):
- not an object: nothing to walk.
- `op` unknown or absent (so `{}` gives the `op` sentence alone): no kind of line exists to judge.
- `by` blank: not about the line, and the line cannot fix it.
- window unreadable (`WINDOW_TEXT`): needs a file the line cannot fix; reported alone so the role restores it first.
Decision note: today `by` and the window were checked LAST. They moved to the front because the dispatch asked for them alone. A line with a shape problem and a blank `by` now reports `by` only (was: the shape problem). Nothing refused today becomes accepted.

Unusable values: `kind` not in the list (a list is fine, no crash): no default oracle, oracle judged only if the line states it. `probe` not an object: no nested checks, status rule skipped. `evidence_refs` not a list: only the absent sentence, no judge. `origin` broken: its sentence, target comparisons skipped. Link not an object: its sentence, no id lookup. No TypeError/KeyError escapes (rows below).

Register read: `_scan` still runs after the shape checks. An `OSError` re-raises as before when the line has no problem of its own; when it has, the line's ValueError is raised, as before (a shape problem used to win).

Limit: no cap. A line's problems are bounded by its keys: max for a known-keys `add` is about 5 code-set + 2 origin + 2 per evidence ref + about 20 others; unknown and excluded keys add one sentence per key.
