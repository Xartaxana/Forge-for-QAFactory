## Decisions inside the spec's silence (small, on the safe side, for acceptance)
1. A launch with NO entries at all (`results: []`) is `repeat: "no"` (nothing to repeat). A launch whose entries are all unnamed has an empty named set: against an earlier launch with the same empty set it reads `not established`.
2. Order of the repeat verdicts: no earlier launch of the set -> no; both fingerprints non-empty and different -> no; seeds differ -> no; then (a missing/empty fingerprint or an unnamed entry) -> not established; else yes. So "seeds differ + fingerprint absent" = `no` (the safe side).
3. In `_block_launches`, a chosen last block that is an import / non-run purpose ends the attempt as skipped (not a fall back); only a shape-damaged block falls back.
4. Seeds are compared with `==` on the raw values (dict equality).
