## Divergences from the spec (reality vs spec) and observations

- DoD 1 says the contract is read ONLY through `handoff.index/template/spec/is_placeholder/set_value`. I also import the reader functions `handoff.relaxed_sections`, `handoff.rows_owed`, `handoff.null_outcomes`, `handoff.owned_by_contract` and the constant `handoff.REQUIRED_LISTS` — otherwise I would copy their rules (`required_when`, `rows_owed_when`, the null-outcome block), the exact thing axis 28 / AR-13 forbids. Veto = tell me and I read `template(c).data` instead.
- FINDING (reality): `handoff_check.check(fix=False)` judges only the nodes PRESENT in the form. Omitting a required scalar (`scope[].state`, `header.verdict`, `scope[0].reason` via `overrides ... ABSENT`) gives NO problem (measured on `s3-strategist-to-designer`; only code-fill blanks remain). So E20 "ABSENT on a required field -> the reader must refuse" does not hold for `check`; the table row asserts only what the filler does (field left out). A section left out under `rows_owed_when` IS refused (negative row passes); an owed `required_when` section left as the template IS refused (negative row passes); `scope: []` without a null outcome IS refused. P1-b seeding refusals through `ABSENT` on a scalar will not seed any refusal from this reader.
- `ctx.minted`, `ctx.case_id_form`, `ctx.cases/bugs/requirements/files/dispatches` are carried but not used: no field of a form cites an id of another form at N1 (the citing `plan_row` is code-filled, `_code_fills`), so `variants()` returns no `cite_hint:<path>` and nothing needs `minted` (N2b/N3).
- Literal template values with tokens that are NOT in `context_tokens` stay as written (the reader accepts them): `work/handoffs/<the analyst's dispatch>.yaml`, `<the automator's file>`, `<the designer's manual file>`, `<the gate A file>`, `<the gate B file>`, `<the gate B decision file>`, `<cases_root>/<case>.md`, `<instance>`, `<case>`. N3 / P1-b need them real for readers of the accepted forms.
- Id hints with no prefix (`<case id>`, `<instance id>`, `<gap id>`, `<backlog id>`, `<obligation id>` ...) are filled as free text `filled <leaf>`: the case id form is a N2b matter.
- `<true|false, or omit when ...>` is read by the reader's spec as a CHOICE (`['true', 'false, or omit when ...']`), so `false` would not pass the reader's option list; the filler writes `true` (as the spec says).
- Variant counts: every variant is crossed with every verdict word (no cut); alt variants `alt:k` take the k-th alternative where a field has one and the base elsewhere.
- `blocked.*` is filled like any other section (the reader treats it as optional); `omit_optional` applies only to hints the reader's spec reads as optional.
