## Decisions taken that the spec did not state (flagged for acceptance)

1. `rows_for` / `row_for` take a keyword `data=None` (a rows dict) so tests inject rows; None reads the real file through `load_rows`.
2. `row_for` falls back from the exact id to the row `<stem>:*` (spec §3.5 E1 says an id is covered by exactly one row, exact first, else `<stem>:*`).
3. `rows_for` unknown/unstated `when` token HOLDS (parent 2.4 error direction (2): more text, never an omitted row); a dispatch token is read from `dispatch` facts
   `{token: bool}`; the conductor's facts are `{"moves": [...]}`. `["*"]` roles = the roles of `inject-map.json`, never the conductor.
4. `told_text` carrier wordings the spec leaves open: `REQUIRED_ROW_FIELDS` = `` `name`: what `` joined by `; ` (built from the carrier here: `window_record.row_field_lines()` does not exist
   in this tree); `role-commands.json` = `<input>; how to prove it: <verify>`; an unreadable row/carrier reads "(the factory's requirement row X could not be read: why; this is a factory defect)".
5. `fill`: an empty-string value counts as missing (placeholder kept).
6. `_keys_outputs` with a file `load_rows` cannot read adds no "The gate also reads" lines (as a lost file did before); a `NOT KNOWN` line would change every page of a tmp plugin root - not done (AR-28 candidate, question 2).
7. `_shape_problems` checks `when_kinds` (distinct non-empty texts), `when_exclusive` (lists of >= 2 kinds that are in `when_kinds`), `told_ratchet` (counts).
8. Nested wrappers: the INNERMOST wrapper's id is the key (matches `with_check`, which keeps the first check set).
