## Written file shape (one example, `bar --stand s --story t --model m`, no transcript, no result)

```
schema: scoreboard/1
run: {stand, story, arm: free, run_class: live, models: [m], model_verified: false, started: null, truth_version: null,
      transcripts: [], results: [], model_note: "the model id was not verified: ..."}   # model_note only when unverified
rows:  every row id of rows.json in its order, each {name, value, unit, source, state, why}
  X1 / T1 / T10 / QA rows: measured|unknown with values; all others: state n/a, value null, source none, why "no such part in a free agent"

```
File names only (no absolute path, AR-4). Written to `<out-root>/<stand>/<story>/bar-<model>.yaml`; printed line `wrote <path>` or `replaced <path>`.

## Edge behaviour as built

- Transcript absent / empty / torn / not UTF-8: `X1`, `T1`, `T10`, tool calls, refused calls `unknown` with the reason; file written. One of several unreadable: all derived rows `unknown` (a partial sum is a lower bound; consistent with `bar_price`).
- Two transcripts: X1 summed (`bar_price`), T1 = earliest event to latest event, T10 and tool calls summed.
- No readable timestamp: `T1 unknown` ("no readable timestamp in the transcripts"). T10 `unknown` when any refused call has no measured execution time (`friction.seconds_text` reason), else measured (a readable transcript with no refused call = measured 0, the package's rule).
- Result without `total_cost_usd` or unreadable: `free.host_total_usd: unknown`; without `num_turns`: `free.turns` unknown; X1 untouched in both.
- Model: refusal naming both (the id and the transcripts' `message.model` values) when readable transcripts name other models; with no readable model, file written, `run.model_verified: false`, `run.model_note`, and X1's `why` says so.
- `--model/--stand/--story` with `/`, `\`, `..`, empty: `SB._safe` refusal, exit 2, nothing written. `--truth` xor `--judgment`: refusal "--judgment is missing" / "--truth is missing". A `read_judgment` refusal passes through.
- Existing file: overwritten by the same single write site, line says `replaced`. All validation precedes the one write.
- Read back: test writes a bar, runs `scoreboard.py assemble --bar` (exit 0) and `scoreboard_bar._bars` (no notes) and `release_lines` (no note line).

## Decisions I made that the card did not name (please confirm)

1. rows.json has no row for turns or for tool calls by name: they are kept under a `free:` block, not as rows (a new row would be a `rows.json` edit, a non-goal).
2. Of the rows.json rows the free agent HAS a part in, I took T1 (first to last transcript event), T10 (refused calls' execution seconds, `exec_s` from `call_spans`; the factory side computes T10 elsewhere, not shown in what I read) and X1. T9 (bookkeeping scripts of the factory) is `n/a`. If T10 should use `turn_s` instead of `exec_s`, one word changes.
3. "Result with no total_cost_usd -> price unknown": read as `free.host_total_usd: unknown`, X1 stays the re-priced value (the existing N7 rule: the host figure is never part of the value).
4. T1 needs every event's timestamp, not only assistant requests, so `_event_times` is a small timestamp-only loop (parsing through `friction._when`, a private name of the package, imported not edited). Tool calls and refused calls go through `friction.call_spans` only.
