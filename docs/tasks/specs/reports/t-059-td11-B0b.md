## What each check does now

- Discovery: `fixtures/*-layers.json` (glob; zero maps is a FAIL, not a vacuous pass). Per map: the `family` header gives facade, prefix, class, cut, installed. File set = `scripts/<facade>.py` + sorted `scripts/<prefix>*.py` minus `not_driver`. Class regex `^<Class>[A-Za-z0-9]*$`; census keys `<Class>.<member>`.
- L10 first: `header_problems` (header shape, `cut` in mixins|functions, mixins needs a class, `installed` bool, prefix ends `_`, facade file exists, `layers` shape, `setup_import` str stem, `module_statements` object with homes in `layers`, `allowed_importers` rows exactly {importer, part, reason}, part a file of the family, reason non-empty). A non-empty list returns at once: `info["skipped"]` set, no other check of that map runs, the runner prints one `SKIPPED` line and only L10 is judged (a malformed map cannot print ok for a check it did not run). Other maps still run. A map with no header is reported by file name.
- L1/L2/L5/L7: as before, family-parameterised. L5 pin is per family (`PINNED_EXCEPTIONS` dict keyed by facade stem, `pinned_for()`; unknown facade = empty).
- L3/L4/L9: tables `attributes`, `adhoc_attributes`, `state_keys`, `dynamic_state_keys`, `string_dispatch`, `stdout_writers`: a check over an absent table is not run; ONE info line per family names the absent tables. `class: null`: one info line, class clauses not run.
- L6: no import of a higher-ranked module (both cuts, unchanged).
- L8 (critic M8): every file name of the family set counts in `scripts/tests/*.py`; temporal rule, `l8_extra` and its printer removed. Skips: `harness.py`, this file, plus the per-facade instrument table `L8_SKIP_BY_FACADE`.
- L11 (new): (a) scripts/*.py outside the family (not `tests/`, not `tools/`) importing a part (any depth, plus literal `import_module("x")` / `__import__("x")`) need an `allowed_importers` row; an unmatched row is stale. (b) `installed: true`: every part in `layers` has a file and a literal `import <part>` in the facade, exactly one `module_facade.install(__name__, [<parts>])` call with a literal list of names in rank order (low first), and the facade defines no name whose home is a part. (c) `installed: false`: an install call in the facade is a problem, and (b) is not run (info line).
- L12 (new, critic m6): `<Class>.<m>` / `<Class><Suffix>.<m>` resolves only for the assembled class, or exactly `<Class><Camel(area of home of m)>`; an unknown class is reported naming it as written (`DriverTypo`), a wrong mixin names the expected one (`DriverCore.role_words` -> `DriverDialog`). `cut: functions`: a part importing a part of EQUAL rank is refused (higher stays L6); mixins keep the L6 rule alone.
