## What was done

s5_precheck.py
- `_passable`: every finding except tags `open-oracle-asserted-*` and `then-remainder-unrecorded-*` (new `NOT_PASSABLE_TAGS`). `_by_tag` is gone; `PASSABLE` and `WORD_PASSABLE_TAGS` constants are KEPT (other tests and the unchanged `report` tail read them; 30b rewrites the tail).
- New `_names(finding, match)`: the ONE selection rule for every family. A word names a finding iff it is `*`, the finding's whole id, the finding's tag whole (`contract.names_whole(match, tag)`), or the stage-wide word of a `WORD_PASSABLE_TAGS` family (`changed-after-red` names `changed-after-red-<...>`). A case id, a phrase of message/fix/printed line, a part of a tag name nothing.
- New `_judge_words(task_root, findings, notes) -> (standing, passes)`: live words via `contract.live_stage_overrides` (revoked acts nowhere), blank / `<placeholder>` match dropped (`waiver.PLACEHOLDER_RE`), first naming word in file order wins, `_words_for_pair` time rule for findings with `pair_at` (`predating` as before). `passed_by_word` (name, signature and note text kept) = `_judge_words(...)[0]`.
- New `word_passes(task_root, scope=None, dispatch_id=None)`: PURE, `[{finding_id, decision, at}]`, filtered to the scope cases (findings with no case, id `<check>:-:<tag>`, belong to every scope). Derived from `run`, so it is exactly what the exit gate judged.
- `run(task_root, dispatch_id=None, scope=None)`: new optional `scope` kwarg (cases to judge when the caller knows them better than the state view); result gets top-level `word_passes` (`[]` with no words, never absent).

controller.py (functions of the list only, plus one helper, see deviations)
- `_record_person_pass`: adds `word_at` (the word's `at`, only when present) and, when `block` was cut at 400, a `finding_id` field holding it whole. Cuts 400 / 1000 stay. Old lines need nothing.
- New `_record_s5_word_passes(d, state)` and ONE call line right after the `_raise_all(... _s5_completion_problems ...)` line (inside `if d["stage"] == "S5" and p.get("stage_complete")`): only an ACCEPTED completion records. Lazy import of `s5_precheck`; any failure -> one stderr line `passed-by-person: not recorded (<why>)`, completion stays accepted.
- `_s5_gap_problems`: an instance whose `run_mapping:<case>:no-row-<iid>` finding was word-passed is dropped from `other_gaps` only (new helper `_s5_no_row_passed(d)`); other gaps, other instances, and a reader that cannot answer still refuse. `gaps` (the `passed_green` rule) is untouched.
- `_plan_refusal`: records the pass through `_record_person_pass("S5", None, passed)` when the word passes it; nothing when it refuses.

branch_accounting.py (`s5_problems` only, plus two small helpers `_word_passed_ids`, `_no_row_passed`)
- A problem "Then N has no home" for an in-scope case is passed (becomes a note, the fact stays visible) iff the manifest has NO `then_bindings` row for that (case, Then) AND `word_passes` holds `bindings:<case>:no-bindings` or `bindings:<case>:unbound-<N>`. Same reader as the first detector; a Then with a row (e.g. bound to an instance the manifest does not hold) is never passed, `*` included.

tests: test_s5_precheck (3 new functions + 5 adapted fixtures), test_branch_accounting (1 new function), test_words_doors (2 new functions + row 21 adapted). Fragment `changelog.d/fv1-30a-word-passes.md`.
