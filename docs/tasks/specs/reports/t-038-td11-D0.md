## Deviations / judgments (marked, for the Lead)
1. The test loads `scenario_clock.py` by path (importlib), not `import scenario_clock`: the real-file check in this same test file (line ~488) requires `covers` to name every tests/*.py
   a keep file imports, and `test-layers.json` is not in my owns. Needed from integration (NC-D): `covers` of the row `test_selftest_slow_tests.py` += `scripts/tests/scenario_clock.py`
   (and `scripts/tests/clock_sitecustomize/sitecustomize.py`); after that a plain import is fine and `--witness-for` picks the file.
2. Interval rule (my choice, documented in the module docstring): the gap before an event's end belongs to that event's scenario. Pool threads (side_by_side) interleave, so
   per-scenario wall for pool files is approximate; child seconds by script are exact per child (start to wait return).
3. Exit code in the `file` row: `harness.finish`'s SystemExit code, else 0, else 1 on an uncaught exception. `os._exit` or a raw `raise SystemExit` outside finish leaves no/odd row: no file row = refusal.
   `run` prints the real exit code and says when the clock recorded a different one.
4. `run` deletes `<stem>.jsonl` and `<stem>.stdout.txt` of the files it is about to run, so a rerun never appends.
5. A child never waited is not recorded (no event at exit).

## Workflow file, full text (`.github/workflows/scenario-clock.yml`)
```yaml
# The per-scenario clock (TD-11 node D0, spec docs/tasks/specs/td-11d-world-per-file.md section 3): runs the named package test
# files under ai-packages/qa-factory/scripts/tests/scenario_clock.py and uploads the sinks and each file's full stdout.
# A MEASUREMENT on demand: workflow_dispatch ONLY (no push, pull_request or schedule trigger), read-only, no secrets.
#   inputs  files  space-separated test file names (bare names from scripts/tests, e.g. "test_story_run_loop_b.py test_no_move_seam.py")
#           ref    branch or sha to measure (empty: main)
#           order  normal | reverse; reverse is exported as QA_SCENARIO_ORDER=reverse (witness of order independence);
#                  normal exports nothing
# Read the result: download the artifact scenario-clock, then
#   python -B ai-packages/qa-factory/scripts/tests/scenario_clock.py report --sink <unpacked dir> [--builders a,b,...]
# (builder names are data of that command line). `python tools/ci_read.py start --workflow scenario-clock.yml --ref <branch>`
# starts it. A red test file makes the run step red, but every named file still runs and the artifact is uploaded (if: always()).
name: scenario-clock
run-name: scenario-clock ${{ inputs.ref || 'main' }} ${{ inputs.order }}

on:
  workflow_dispatch:
    inputs:
      files:
        description: "space-separated test file names from ai-packages/qa-factory/scripts/tests"
        required: true
      ref:
        description: "branch or sha to measure (empty: main)"
        required: false
        default: main
      order:
        description: "scenario order: normal or reverse"
        required: false
        default: normal
        type: choice
        options: [normal, reverse]

permissions:
  contents: read

env:
  PIP_DISABLE_PIP_VERSION_CHECK: "1"
  PYTHONUNBUFFERED: "1"

jobs:
  scenario-clock:
    runs-on: ubuntu-latest
    timeout-minutes: 180
    steps:
      - uses: actions/checkout@v7
        with:
          fetch-depth: 0
          ref: ${{ inputs.ref || 'main' }}
      - uses: actions/setup-python@v7
        with:
          python-version: "3.12"
      - run: pip install -q pytest
      - run: |
          git config --global user.name "forge-ci"
          git config --global user.email "forge-ci@invalid.example"
          git config --global init.defaultBranch main
      - name: run the named test files under the clock
        env:
          FILES: ${{ inputs.files }}
          ORDER: ${{ inputs.order }}
          REF: ${{ inputs.ref || 'main' }}
        run: |
          set -eu
          TESTS="$GITHUB_WORKSPACE/ai-packages/qa-factory/scripts/tests"
          OUT="$GITHUB_WORKSPACE/ci-out/scenario-clock"
          mkdir -p "$OUT"
          if [ "$ORDER" = "reverse" ]; then export QA_SCENARIO_ORDER=reverse; fi
          PATHS=""
          for name in $FILES; do
            case "$name" in
              test_*.py) ;;
              *) echo "refused: '$name' is not a bare test file name (test_*.py)"; exit 2 ;;
            esac
            case "$name" in
              */*|*\\*) echo "refused: '$name' carries a path separator"; exit 2 ;;
            esac
            if [ ! -f "$TESTS/$name" ]; then echo "refused: $name is not in scripts/tests of ref $REF"; exit 2; fi
            PATHS="$PATHS $TESTS/$name"
          done
          if [ -z "$PATHS" ]; then echo "refused: the files input names no test file"; exit 2; fi
          python -B "$TESTS/scenario_clock.py" run --sink "$OUT" $PATHS
      - uses: actions/upload-artifact@v7
        if: always()
        with:
          name: scenario-clock
          path: ci-out/scenario-clock/
          retention-days: 14
          if-no-files-found: warn
```
