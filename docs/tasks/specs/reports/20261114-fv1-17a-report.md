## Frozen CLI contract of the roads command (as built, card item 6)

```
python -B stand_access.py --project-root DIR --roads [--env NAME] [--command "<cmd>"] [--candidate <kind>=<url>]...
                          [--user-key NAME --secret-key NAME] [--no-negative] --json
```
- stdout: one JSON object, exit 0 always (a report; writes nothing). `--json` is accepted; the output is JSON with or without it.
- exit 2, stderr text, nothing sent: no `--roads`; `--user-key`/`--secret-key` not a variable NAME (the value is never echoed);
  a `--candidate` that is not `<local_login|oidc_password>=<url or path>` (text: "a candidate is <local_login|oidc_password>=<url or
  path>"); `<root>/qa-factory/config.json` unreadable as a JSON object. (argparse's own refusals exit 2 too.)
- `--candidate` repeatable; kinds `local_login` / `oidc_password`; at most `budget.candidates` (5) tried.
- Output:
```
{"roads": [{"road": "a" | "b:<form id>" | "c" | "d:<n>", "kind", "access": {names, command, url through _safe; no login_probe},
            "status": ok|failed|skipped|not_recorded, "answer": <word of ANSWERS>, "why", "negative"?: refused|passed|not_run,
            "record"?: <the probe's login.record>}],
 "first_in": index into roads | null (a hint), "tried": n (roads whose answer is not not_tried), "spent": k,
 "budget": {"real_secret_failures": 1..3, "candidates": 1..5}, "budget_note"?, "forms_note"?, "candidates_note"?,
 "table": "ok" | "unreadable" (references/login-roads.json: unreadable = no valid form row)}
```
- road `d:<n>`: n = 1-based position among the given `--candidate`s. Stops (later roads listed as `status skipped`, `answer
  not_tried`, with the why of the card): 429 ends the run; `credentials_refused` ends it ("refused at road <n>", n = 1-based
  position in `roads`); the Nth spending answer ends it (N = `real_secret_failures`). `negative` is present only on the FIRST harness
  road that is `in`; `passed` appends the card's words to its `why` and the answer stays `in`.
- Library: `stand_access.try_roads(full_cfg, root, *, env_name, command, candidates, user_key, secret_key, negative)` returns the same dict.
