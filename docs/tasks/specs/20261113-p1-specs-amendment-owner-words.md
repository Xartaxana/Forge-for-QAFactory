## B2. Храповик красных норм

### Слова владельца
«сейчас только предупреждение; строка, по которой фабрика в выпущенной версии стала ЛУЧШЕ агента, закрепляется, и её ухудшение в
следующем релизе выпускается только по слову владельца» (план `:280-281`).

### Форма данных `experiments/scoreboards/norms.json`
```
{"schema": "norms/2",
 "rows": {"<row id>": {"norm": <value>|null, "unit": "<unit>", "better": "lower|higher",
                       "ratchets": [{"pair": "<agent model id>/<story>", "factory_model": "<model id>",
                                     "since": "<package version>", "value": <value at ratchet>,
                                     "bar": "<stand>/<story>/bar-<model-id>.yaml"}],
                       "raises": [{"raised_by": "<who>", "reason": "...", "word": "<owner, date>"}],
                       "worsened_passes": [{"version": "<v>", "pair": "<agent model id>/<story>", "word": "<owner, date>", "quote": "..."}]}}}
```
- Закрепление: `scoreboard.py compare --release <version>` на табло ВЫПУЩЕННОЙ версии печатает `can ratchet: <row> <pair> <value>
  better than bar <bar file> (<bar value>)`; Lead коммитит элемент `ratchets` (F-B2-1 (а)). Строка в состоянии `one_source`,
  `range`, `at_least` или `unknown` предложением не печатается. `norms --check` (K5) отказывает правке, которая удаляет элемент
  `ratchets` или ухудшает его `value` без строки `raises` со словом владельца.
- `compare --release <version>` перебирает ЗАКРЕПЛЁННЫЕ строки из `norms.json` (не строки текущего табло): для каждого элемента
  `ratchets` ищет значение строки в табло текущего релиза для той же пары и той же модели фабрики и печатает ровно одну строку:
  - `release: owner's word needed -- <row> <pair> was <v_prev> (<ver_prev>) now <v_now> (<ver_now>)` — «хуже» по таблице B1;
  - `release: owner's word needed -- <row> <pair> not decided: <range|lower bound> (<v_now>)`;
  - `release: owner's word needed -- <row> <pair> unknown: <why>`;
  - `release: owner's word needed -- <row> <pair> no value in this release (no scoreboard for the pair)`;
  - `release: owner's word needed -- <row> <pair> no comparable measurement (factory model <a> vs <b>)`;
  - `release: ok -- <row> <pair> not worse`;
  и для незакреплённых строк текущего табло: `release: warning -- <row> red: <value> against norm <norm>`; без прошлого
  выпущенного табло — `release: no previous release -- ratchet not judged` (закреплённых строк тогда нет).
- Диапазон против диапазона (прошлый релиз дал `range`): «хуже», если `low_now > high_prev`; «не хуже», если `high_now <= low_prev`;
  иначе `not decided: range` → `owner's word needed`.
- `release-check` (K3): выход 0, если у каждой строки `owner's word needed` есть `worsened_passes` с этой версией и парой; иначе
  выход 1 с перечнем; предупреждения выход не меняют.
