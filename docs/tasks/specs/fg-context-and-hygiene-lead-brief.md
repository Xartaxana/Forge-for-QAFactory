## Что построить

### A. Хук после сжатия (FG7-25)

После любого сжатия контекста (ручного и автоматического) лид получает в контекст: путь к самому свежему снимку
`docs/tasks/compact-snapshots/*.md`, список открытых диспатчей журнала (то же, что печатает SessionStart) и строку «прочитай
снимок до следующего действия». Хук перед сжатием (`PreCompact`, пишет снимок) уже есть — сверить, что он срабатывает на
автосжатии, а не только на ручном (калибровка: одно сжатие 11.11 21:09 прошло без снимка).
Не проверено лидом: какое событие хоста срабатывает ПОСЛЕ сжатия (`PostCompact` или `SessionStart` с источником `compact`) —
один опыт до проекта (гигиена 6а).
Сделано лидом сразу: `autoCompactWindow: 350000` в `.claude/settings.json` (слово владельца).

### B. Короткая сдача исполнителя

Итоговое сообщение исполнителя лиду: путь к отчёту, по строке «пункт — сделано / не сделано / вопрос», вопросы. Вывод
прогонов, таблицы и следы — в файле отчёта, не в сообщении. Сверить с проверкой 28 протокола калибровки («полнота итоговых
сообщений», якоря в `.claude/agents/*.md`, `tools/test_handoff_rule_anchors.py`): полнота переезжает в отчёт, правило и его
детектор меняются вместе. Цель по размеру сообщения — выбрать и назвать (сегодня сдачи по 2–4 тысячи токенов).

### C. Гигиена команд: что остаётся и почему

Ответ лида на вопрос 3: правило «каждая нестандартная форма — запрос разрешения оператору» написано под режим с
подтверждениями. В режиме авто его мотив отпал. Для качества и командной работы нужны четыре запрета, остальное снимается:

| Поведение | Вред | Что делать |
|---|---|---|
| смена каталога (`cd`, `Set-Location`, `Push-Location`) | хуки ищут `tools/` от cwd — после смены блокируются все инструменты, сессия себя не вернёт (PROJECT.md) | ОТКАЗ с дверью: `git -C <путь>`, `python -B <абсолютный путь>`, `--repo`/`--root` |
| правка файлов разовым скриптом (`python -c`/heredoc с записью, `sed -i`, перенаправление в файл репозитория) | правку не видно в диффе инструмента, её не ловят хуки Edit/Write (журнал, гейты) | ОТКАЗ с дверью: Edit/Write или именованный закоммиченный скрипт |
| запись журнала мимо Edit/Write | `journal_echo` не проверит строку | ОТКАЗ с дверью |
| откат `git checkout --`/`git restore` без проверки `git status --porcelain -- <файл>` | стирает незакоммиченное соседней сессии | ОТКАЗ с дверью: побайтная копия |
| составные команды, переменная впереди, циклы, `python -c` для чтения и расчёта, `grep`/`cat`/`sed` без записи, `2>&1` в Bash | в режиме авто — никакого | РАЗРЕШИТЬ: убрать из правила и из предупреждений; аудит не считает нарушением |

Открытое для дизайнера: `2>&1` в PowerShell 5.1 портит код возврата нативных команд — оставить ли предупреждение только там;
циклы ожидания (`until`) — это вопрос цены, не гигиены (правило 7: фон вместо опроса).
Носители, которые меняются вместе: `CLAUDE.md` «Command hygiene», `tools/hygiene_gate.py`, `tools/permission_audit.py`,
проверка 27 протокола калибровки, файлы ролей, `docs/SIBLING_MAP.md`.

### E. Гейт диспатча (FG7-18, FG7-20) и быстрый набор перед пушем (FG7-19)

Как записано в сводке калибровки: `tools/dispatch_manifest.py` по каждому пути `owns` печатает в диспатч тесты-свидетели
(`scenario_walk.py --witness-for`) и носители, называющие файл; требует строку `siblings:`; считает порог дизайнера и требует
строку о черновике или причину пропуска. Интегратор перед пушем в `main` гоняет быстрый реестровый набор (слои драйвера,
реестр медленных, аудит, реестр гейтов, храповики).
