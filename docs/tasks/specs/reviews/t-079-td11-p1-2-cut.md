none was missed.** `_now` reaches 11 parts, `_append_jsonl` 5, `lane_keys` 2, `time` 6, `json_record` 4, `open` 1

`driver_timing.time`, and `story_run.<n>` now exposes driver_timing/driver_chains names (`console`, `row`, `watch`,

patch. The direction is an over-patch: a test that swaps `time` for a namespace copy of `time` (test_story_run_wait,
quarantined) is unaffected. Noted, not a finding.

(b) None of the forms this question lists occurs in a moved member: no `global` statement in any part and no
name-mangled `self.__x`, by AST scan. `super()` appears only in exception classes that moved whole (Refusal, Person,

by driver_core `HERE` (the same directory). Every `.__name__` read is `type(x).__name__` or a function name, which the
move leaves unchanged. Not covered by the move: exception classes now report `__module__` `driver_core` instead of
`story_run` (traceback text only; every `except story_run.Stop` test still matches by identity). Test-side readers that
DO see the change are listed under 6.

(c) No import cycle (see 1: 15/15 standalone imports).

(d) `python -B story_run.py --help` → usage, exit 0. Through `run_py_entry.py story_run.py --help` → usage, exit 0. Through
`run_py_entry.py story_run.py --task X --side bad` → the argparse refusal of `side_flag`, exit 2: `main`, the nested
`stage_done` import and the facade work as `__main__` under run_as_main.
