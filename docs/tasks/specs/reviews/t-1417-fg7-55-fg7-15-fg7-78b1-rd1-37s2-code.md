**D1 (fix before merge; Q1 round-2 Lead decision "discover refuses every other shape").** `_module_list`
(driver_golden.py:246) and `_scenario_arg` (:257-279) accept four shapes that are none of (i)-(iii). In each one the
discovered set is not what runs. Scratch probe `p78.py` (temp roots, `discover` imported read-only):

| shape | discover answer | what really runs |
|---|---|---|
| `ALL = [a]` then `ALL.append(b)` | ACCEPTED `inproc=['a']` | a, b |
| `ALL = [a]` then `ALL[:] = []` | ACCEPTED `['a']` | nothing |
| `ALL = [a, b]` and `def main(ALL=[]): run_scenarios([], ALL)` (parameter shadows) | ACCEPTED `['a', 'b']` | `[]` |
| `chosen = [pick for s in ALL]` (element is not the target) | ACCEPTED `['a', 'b']` | other objects |

Correctly refused: a call, a name bound twice, a comprehension over a call, an attribute, an alias, a concatenation.
Correctly accepted: a literal, a module list, a comprehension over a module list.
- Cause: `_bindings` counts only `Name` Store nodes. It does not see a mutation through an Attribute or Subscript, a
  parameter (`ast.arg`), or the comprehension element.
- No live file uses these shapes (53 files, 432 units, reproduced). The builder's round-2 witness says itself "no
  negative control for the new discover shapes beyond the live tree" (rule 7). That is why this escaped.
- Fix:
  - Refuse when the name is the `.value` of an Attribute or Subscript anywhere in the file.
  - Refuse when the name is an argument of the calling function.
  - For (iii), require `elt` to be a Name equal to the generator's target.
  - Add the four rows above as negative controls to the witness script.
