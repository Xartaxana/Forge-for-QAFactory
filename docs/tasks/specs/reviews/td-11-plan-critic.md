## Блокеры

**X1. Пересылающий фасад по тексту спеки B §2.4 несостоятелен** (доказано опытом во временной папке: части `p_core`,

- (а) Выход из `mock.patch.object` удаляет имя из всех частей, а возврат исходного значения ложится только в фасад:

  `test_controller_brief.py:195`, `test_resume_stopped.py:171` и др.; всего 220 мест `mock.patch.object(` в 51 файле.
- (б) Подмена встроенного имени теряется: `test_story_run_words.py:286` ставит `story_run.open`, читает её
  `Driver.words_file` (`story_run.py:1459`); после резки ни одна часть не связывает `open`, запись через фасад не
  доходит. Этот тест стоит в DoD самого узла резки.
- (в) Собственный код фасада (`main`, тело класса) теряет перенесённые имена: `__getattr__` модуля не обслуживает
  поиск глобальных имён внутри самого модуля. Доказательства P1–P7 инструмента этого не видят.
- Правка: `install` при установке записывает по каждой части имена, которые часть связывает, И глобальные имена,
  которые её код читает (`co_names`, включая встроенные); запись и удаление идут по этому записанному набору;
  инструмент разрешает свободные имена кода, оставшегося в фасаде, в `from <часть> import`; в DoD узла B0 — таблица
  подмен (присвоить и вернуть; `patch.object` дважды; `create=True`; встроенное `open`; запуск как `__main__` и через
  `run_py_entry.py`). После правки отказ от `patch_driver_global` и L11 спеки A безопасен.

console_io.utf8_stdio(stdin=True)`) — побочное действие при импорте для каждого хука; инструмент его молча теряет,
