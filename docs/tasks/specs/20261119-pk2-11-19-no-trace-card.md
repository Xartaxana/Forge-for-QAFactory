## §2 The ONE refusal: home, signature, carriers, every edge

Home: `ai-packages/qa-factory/scripts/external_writes.py`, beside `closed_by_run` (the module that already owns the experiment record; no new module, so no new layer row). Two functions, one rule:

```
trace_state(task_root, launch=None) -> tuple[str, str]     # (state, carrier); never raises
trace_refusal(task_root, launch=None) -> str               # "" | NO_TRACE_WORDS | UNKNOWN_WORDS; never raises
NO_TRACE_WORDS  (moved here, text byte-identical to today's project_knowledge.NO_TRACE_WORDS; PK keeps the name as an alias)
```

`state` is `open` | `closed` | `unknown`; `carrier` is `pipeline` | `launch` | `none` | `no_story`. `launch`: the driver's in-memory `state["launch"]` (a newer copy of the same carrier; only `Driver` passes it); when given it replaces the file read of `driver-state.json`, under the same rules.

Carriers, in order:
1. `<task_root>/pipeline.json`, key `no_trace` (written at the end of S0, or by `stage_done --set no_trace=true|false`, FR-40).
2. `<task_root>/state/driver-state.json`, object `launch`, key `no_trace` (written by `driver_s0.py` from the first S0 step, before the first S0 stop).
3. None other exists: scout t-1573 found no third carrier; a grep of `no_trace` over `scripts/*.py` (227 hits, 49 files, positive control: `external_writes.py:191 closed_by_run` found) shows only these two records plus the driver's in-process `flags.no_trace` (command line), which only `Driver.no_trace` reads (F2).

Reading: `pipeline.json` and `driver-state.json` through `external_writes.load_json` plus `Path.is_file()` (the module's own reader; `hooklib.read_json` cannot tell absent from broken, which this rule needs, the same reason as `product_gaps._load`'s axis-16 KEPT row).

Decision table (P = pipeline.json, L = launch record). Each row is an edge with its invariant.

| # | P | L | state, carrier | invariant protected |
|---|---|---|---|---|
| E1 | `task_root` is None (no story named) | - | open, no_story | (F1) a write naming no story is an act outside any story; today's `_refuse_no_trace(None) == ""` kept |
| E2 | `task_root` given, not a directory | - | unknown, none | a named story that cannot be found is never read as "no story" |
| E3 | key `no_trace` truthy (incl. a non-bool truthy like `"yes"`) | any | closed, pipeline | the pipeline's yes is never reopened by any other carrier |

Disagreeing carriers: E3 (P yes, L no) -> closed; E4 (P explicit no, L yes) -> open; E5 (P silent, L yes) -> closed. Rule in one line: the launch record can only CLOSE; only an explicit pipeline `false` opens over it.

`trace_refusal` text: closed -> `NO_TRACE_WORDS` (today's text, byte-identical: "an experiment leaves no trace: the answer stays in this story's words (waiver); nothing was recorded"); unknown -> `UNKNOWN_WORDS`, exactly: "whether this story is an experiment that leaves no trace could not be established: <what> of the story cannot be read; start or resume the story with the driver (its S0 records it), or repair that file, then run the same command again; nothing was recorded", where `<what>` is `neither pipeline.json nor state/driver-state.json` (E10, E12), `pipeline.json` (E7, E11) or `the story folder` (E2). Writers print it after their own prefix and exit 2 (CLI) or return it as their `problem` (in process).

Positional invariant for every writer: the call runs AFTER the story is placed (its `--task` resolved) and BEFORE the first byte of ANY file is written, including `qa-factory/config.json` (report_adapt `kind` writes config through `config_contract.apply_adaptation` before its row: the refusal precedes that call). What stays unreachable: a write with a non-open state. Order among a writer's own refusals (bad words, unknown id) is free; none of them may write.

Error direction (the function moves from advice to gate for four modules): it may err only toward `closed`/`unknown`. Adversarial inputs that must stay on the safe side are rows E3, E5, E7, E10, E11, E12 plus: pipeline `{"no_trace": "false"}` (a string -> truthy -> closed), a BOM-prefixed pipeline (load fails -> E11), `launch` a list (-> not an object -> E10/E11 branch), a 1 MB pipeline (read whole; internal file, no cap added).

Two consumers mapped onto the same rule (F2, F3, recommended):
- `Driver.no_trace()` = `True` if closed; `False` if open by `pipeline`; else `bool(flags.no_trace)` (open by launch, unknown, no_story). Differences from today: only toward closed (an unreadable/null pipeline with `--no-trace` on the command line).
- `closed_by_run(task_root, unreadable_closes=False)` = the reason text if closed; the unreadable text if `unreadable_closes` and carrier is not `pipeline`-readable (absent, unreadable, non-object: exactly today's `not isinstance(pipeline, dict)`); else "". Differences from today: only toward closed (L truthy with a keyless, absent or broken pipeline).
