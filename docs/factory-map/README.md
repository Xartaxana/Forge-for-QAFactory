- [Карта с масштабированием и навигацией (HTML)](qa-factory-paths.html) — 14 схем; скачайте и откройте файл в браузере. Все схемы встроены, интернет для просмотра не требуется.

- Отдельные векторные схемы: `graph-01.svg` — `graph-14.svg`; номера соответствуют разделам 1–14 анализа.

Это снимок исследованной ревизии, а не автоматически обновляемая документация.
Работа QA-story при анализе не запускалась. Маршруты, заданные контрактами, отделены
от явных переходов кода; расхождения отмечены символом Δ. Циклы показаны как циклы,
а не как конечный перечень всех возможных последовательностей выполнения.
