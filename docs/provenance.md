# Происхождение истории

## 1. Откуда история

История каталогов `ai-packages/qa-factory/`, `factory-plans/` и `project-artifacts/` в этом репозитории импортирована утилитой git-filter-repo из внутреннего релизного репозитория (источник импорта), ветка `experiment/qa-factory-driver`, коммит `3fbb69b9`. Из 346 коммитов ветки сохранено 207.

- **SHA изменились.** Каждый коммит при фильтрации получил новый хеш. Соответствие «старый -> новый» дала карта `commit-map` git-filter-repo; в таблицах ниже старые хеши сопоставлены новым по префиксу.
- **Старые SHA остаются рабочими** во внутреннем релизном репозитории: там `git show <старый SHA>` находит исходный коммит.
- **Архивная ветка.** В старом репозитории форжа (не переезжает) ветка `archive/experiment-qa-factory-driver` (до 06.10.2026 — `experiment/qa-factory-driver`) хранит нефильтрованный оригинал. Планы из `factory-plans/` удалены из рабочего дерева, но лежат в архивной ветке, в папке `factory-plans/`; факты, пережившие планы, собраны в `plans/MEASUREMENTS.md`.
- Голова импортированной истории: старый `3fbb69b9` -> новый `c6bc0e0c`.
- Все коммиты, названные в документах-дайджестах, найдены в карте и сохранены в фильтрованной истории; хешей «не в фильтрованной истории» среди них нет.
